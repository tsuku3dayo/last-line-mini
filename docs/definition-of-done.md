## TASK（PR）ごと

- [ ] テストの名前の先頭に確認 ID があり、TASK の対象の確認 ID のテストがそろっている
- [ ] 手元で `npm run verify`（lint・単体・build・dist の検査・check:docs）と E2E が通る
- [ ] CI が緑
- [ ] 画面の変更は、PC（1280 × 800）と一番小さいスマートフォンの幅（iPhone SE 第 3 世代 375 × 667）でスクリーンショットを見た
- [ ] TD・スプリントバックログが実装と合っている
- [ ] コミットメッセージ・PR が日本語で、解説が付いている
- [ ] **build したもの（dist）に、原作の名前・ロゴの文字が入っていない（check-dist で自動）**

## PBI ごと

- [ ] 受け入れ条件のすべての確認 ID に、自動テストの結果か実機確認の結果がある
- [ ] プレビューで実機確認をした（「確認できなかったこと」は AC に書いた）
- [ ] **iPhone 11 のプレビューで、`?debug=1` の fps が 55 以上で動く（画面に関わる PBI だけ。iPhone の操作が入る LLM-PBI-0002 からあと）**
- [ ] これまでのインクリメントと一緒に動く（E2E 全体が通る）
- [ ] AC が書かれ、整合性チェックを通った
- [ ] 一時的な診断のコードが残っていない

## 本番に公開するとき

- [ ] 公開する PBI がすべて PO に受け入れられている
- [ ] 画面の版の表示と `package.json` の version が同じ
- [ ] README・権利やクレジットの表記がある
- [ ] **本番とプレビューで、アプリの名前・アイコン・保存のキーが分かれている（E2E で自動）**
