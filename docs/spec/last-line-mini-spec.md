# 『最終防衛線ミニ』基本設計仕様書 (TOP10限定版)

版：v1.1（改訂履歴は末尾）

## 1. システム概要と製品コンセプト

本仕様書は、ミサイル迎撃ジャンル（迫り来る敵ミサイルを爆風で迎え撃ち、都市を守る固定画面シューティング）のオリジナル作品として、短時間でのスコアアタック体験に特化させた『最終防衛線ミニ』の基本設計を定めるものである。特定の既存作品の名前・ロゴ・画面の見た目・演出は再現しない。

ジャンルの持つ「迫り来る敵ミサイルから都市を防衛する緊迫感」と「爆風による誘爆の戦略性」をシングルステージ（1面完結）の中に凝縮し、プレイ終了後には上位10位（TOP 10）までのハイスコアのみを記録・提示する厳格なランキング機能を搭載する。

| 項目 | 仕様内容 |
| --- | --- |
| タイトル名 | 最終防衛線ミニ (Last Line Mini) |
| ゲームジャンル | 固定画面 防衛型シューティング |
| プレイ人数 | 1名 (TOP 10限定 オンライン/ローカルランキング対応) |
| ステージ構成 | 1面完結 (シングルステージ・ウェーブ制) |
| ランキング保持数 | **TOP 10（1位〜10位）限定** |
| 操作体系 | トラックボール / 慣性D-Pad ＋ 3拠点独立発射ボタン |

## 2. ゲームルールと1面完結型シーケンス

『ミサイルコマンドミニ』は全1ステージで完結するミニマル設計であり、敵ミサイルの総攻撃を凌ぎ切るか、すべての都市が破壊された時点でゲームセットとなる。

### 2.1 ゲームフロー

プレイセッションは以下の定義された手順に従って進行する。

1. **タイトル・ハイスコア表示**: タイトル画面にて現在のTOP 10リーダーボードを確認し、ゲームを開始する。
2. **1面ゲームプレイ**: 画面上部から降下する敵弾頭および航空ユニットを迎撃する。迎撃ミサイルのリソースと敵弾頭の出現ウェーブを管理しながら防衛を行う。
3. **ゲーム終了判定**:
   * **防衛成功 (CLEAR)**: 敵の最終弾頭が画面上から消滅した時点で、自陣の都市が1つ以上残存していればステージクリアとなる。
   * **防衛失敗 (GAME OVER)**: 地上の6都市がすべて破壊された瞬間、または全拠点の弾薬が尽きて着弾を阻止できなくなった時点で即座にゲームオーバーとなり、「The End」の演出が表示される。
4. **最終スコア算出**: 敵撃破スコアに残存弾薬ボーナスおよび残存都市ボーナスを加算し、セッションの最終スコアを計算する。
5. **TOP 10ランクイン判定**:
   * 最終スコアが現在の10位のスコアを上回っている場合（または保持データが10件未満の場合）、ネームエントリー画面へ移行する。
   * 11位以下の場合はネームエントリーをスキップし、TOP 10リーダーボード画面へ遷移する。

## 3. 防衛・攻撃システム設計

プレイヤーの防衛陣営は、画面下部に配置された3つの迎撃ミサイル基地と、その間に位置する6つの都市から構成される。

### 3.1 拠点および防衛対象の配置

防衛目標と防衛拠点の配置および性能の差異は以下の通りである。

* **迎撃ミサイル基地 (基地A・基地B・基地C)**: 画面下部の左端（基地A）、中央（基地B）、右端（基地C）に配置される。各基地は独立した10発の迎撃ミサイル（計30発）を初期装填している。中央の基地Bから発射される迎撃ミサイルは、左右の基地A・Cに比べて移動速度が速い特性を持つ。
* **都市 (City 1 〜 6)**: 基地間に各3個ずつ、計6都市が配置される。都市は敵ミサイルの直撃を受けると1発で完全に壊滅する。1面完結仕様のため、壊滅した都市の復活処理は行われない。

### 3.2 照準操作と発射メカニズム

照準の移動とミサイルの発射は、アーケードの直感操作と家庭用コントローラの双方に対応した以下の2種類のコントロール形式をサポートする。

* **トラックボール操作**: 入力デバイスの回転速度に応じて照準カーソルが画面内を即座に移動する。画面端から端への迅速なカーソル移動を実現する。
* **慣性D-Pad/キーボード操作**: 移動入力に対して物理的な加速度・慣性パラメータを付与する。方向キーを押し続けることでカーソルが加速し、指を離すと滑らかに減速して停止する。

プレイヤーが基地A・B・Cに対応する発射ボタンを押すと、該当する基地から目標照準位置へ向けて迎撃ミサイルが即座に射出される。ミサイルは一定の飛翔時間を経て到達し、照準位置で自爆して円形の爆風を発生させる。

### 3.3 爆風と誘爆（チェーンリアクション）

迎撃の基本概念は、直撃ではなく爆風に敵ユニットを巻き込むことにある。

* **爆風判定**: 迎撃ミサイルが目標地点に達すると、指定半径まで急速に拡大したのち収縮して消滅する。この半径内に存在する敵ミサイルは撃破される。
* **誘爆（チェーンリアクション）**: 敵ミサイルが爆風に巻き込まれて破壊された際、その地点で二次的な爆風が発生する。これにより、一発の迎撃ミサイルで複数の敵弾頭を連鎖的に撃破する戦略的プレイが可能となる。

## 4. 敵ユニット仕様とスコア設定

1面の中に多様な敵ユニットを集約し、短時間で緊迫した駆け引きを生み出す。

### 4.1 敵ユニット一覧と挙動

敵ユニットは画面上端より様々な入射角と速度で飛来する。

| 敵ユニット名 | 出現特性・挙動 | 撃破得点 |
| --- | --- | --- |
| **アタックミサイル** | 直線的な航跡を描いて都市または基地を目指す基本弾頭。 | 25点 |
| **多弾頭ミサイル (MIRV)** | 降下途中で複数の子弾頭に分離するミサイル。外観上の判別は不可。 | 25点 (各弾頭) |
| **ボム (爆撃機)** | 画面上部を左右方向に横切って飛行し、直下にミサイルを投下する。 | 100点 |
| **キラーサテライト (人工衛星)** | 画面上空を横切る軌道を描き、定期的に弾頭を離脱させる。 | 100点 |
| **スマートミサイル** | 菱型の特殊ミサイル。進行上に爆風が存在すると回避運動をとる。 | 125点 |

### 4.2 スコア算出計算式

ゲーム終了時、以下の計算式に基づいて最終スコアが算出される。

$$ \text{Final Score} = \text{Destroyed Enemy Score} + (\text{Remaining Missiles} \times 5) + (\text{Remaining Cities} \times 100) $$

* **残存弾薬ボーナス**: 各基地に残された迎撃ミサイル1発につき **5点**。
* **残存都市ボーナス**: 防衛に成功し残存した都市1個につき **100点**。

## 5. ランキングシステム詳細設計（TOP 10限定仕様）

スコアアタックの緊張感とリプレイ性を維持するため、保持および表示枠を厳格に**TOP 10（上位10件）**に限定したランキングシステムを構築する。

### 5.1 ネームエントリーおよびランクイン条件

セッション終了時、獲得スコアがTOP 10に入った場合のみ、3文字のイニシャル入力画面が有効化される。

* **ランクイン判定**: 獲得した最終スコアを現在のランキングテーブル（1位〜10位）と比較する。最終スコアが10位のスコアより高い場合（同点の場合は達成日時が新しいレコードを優先、または設定基準に従う）、TOP 10に登録される。
* **入力可能文字**: アルファベット大文字 (A-Z)、数字 (0-9)、記号 (.) の最大3文字。
* **入力インターフェース**: トラックボール/方向キーによる文字選択と、決定ボタンによる確定。

### 5.2 リーダーボードデータ構造

ランキングシステムは、ローカルおよびオンライン環境の双方で上位10件（1位〜10位）のみを厳密に管理する構造をとる。

#### レコードフォーマット

ランキングテーブルに保持されるデータ項目は以下の通りである。

| フィールド名 | データ型 | 説明 |
| --- | --- | --- |
| `rank` | Integer | 順位 (**1〜10 のみ**) |
| `player_name` | String(3) | プレイヤーイニシャル (例: "AAA") |
| `score` | Integer | 最終獲得スコア |
| `survived_cities` | Integer | 残存都市数 (0〜6) |
| `remaining_missiles` | Integer | 残存迎撃ミサイル数 (0〜30) |
| `clear_status` | Enum | クリア状況 (`CLEARED` または `GAME_OVER`) |
| `created_at` | Timestamp | スコア記録日時 (ISO-8601形式) |

### 5.3 保存・同期・データパージロジック

ストレージ容量および通信負荷を最小限に抑えつつ、常に正確なTOP 10を維持する保存アルゴリズムを採用する。

1. **データ保持制限**: ローカルストレージおよびオンラインデータベースサーバーの双方は、最大10件のレコードのみを保持する。
2. **自動パージ処理**: 新規スコアがTOP 10内に差し込まれた場合、最下位となった旧10位のレコード（通算11位となったスコア）はシステムから自動的に削除（パージ）される。
3. **同スコア時の優先順位**: 同一スコアが発生した場合は、先に達成されたレコード（タイムスタンプが古いもの）を優先し、順位を上位とする。

## 6. 画面構成とUIレイアウト

ゲーム画面はシンプルなレトロアーケードスタイルを継承し、プレイヤーに必要な視覚情報を明確に提示する。

### 6.1 メインゲーム画面レイアウト

画面最上部に現在スコアおよびTOP 10の第1位（1st Place）ハイスコアが表示される。画面下部には山並みの地形線とともに3つの基地と6つの都市が描かれる。

* **画面上部 (HUD)**:
  * 左側: `1P SCORE` (現在のプレイ点数)
  * 中央/右側: `TOP 1 HIGH SCORE` (TOP 10中の1位スコア)
* **中央エリア**:
  * 敵ミサイルの航跡線
  * 迎撃ミサイルの直線軌跡と円形爆風
  * 移動するボム・キラーサテライト・スマートミサイル
  * 目標指示クロスヘア（照準カーソル）
* **画面下部**:
  * 基地A、都市1〜3、基地B、都市4〜6、基地C のグラフィック配置

### 6.2 スコアアタック結果・TOP 10ランキング画面

ゲーム終了後、画面中央に「THE END」または「DEFENSE COMPLETE」の演出が表示され、続けてTOP 10リーダーボードが全画面にオーバーレイ表示される。

* **TOP 10一覧表示**: 1位から10位までの全10件のランキング情報が画面内に一括（スクロールなし）表示される。
* **ランクイン強調表示**: 今回のセッションでTOP 10にランクインしたプレイヤーのレコード行が点滅表示（ハイライト表示）され、プレイヤーの健闘が視覚的に祝福される。
