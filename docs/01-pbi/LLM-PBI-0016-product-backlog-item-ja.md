# LLM-PBI-0016 遊んでいる途中で止め、続きから遊べる（ボタンと、アプリを離れたとき）

状態：未整理（次のスプリントのリファインメントで、受け入れ条件・確認 ID・画面〔モックの画像つき〕を足す）

## ストーリー

すき間時間に遊ぶオーナーとして、途中で手が離れても（自分で止めたとき・電話や通知でアプリを離れたとき）、戻って「続ける」を押すまでゲームが進まず、止めたところから続けたい。なぜなら、今は戻った瞬間に動き出し、気づく前に都市がやられてしまうから。

## メモ（決めること）

- 止めるボタンの場所・形（HUD の近く。指で照準や都市を隠さない。iPhone SE の倍率 0.75 で 44 ポイント以上）
- 止めているあいだの画面（文字・「続ける」「やめてタイトルへ」のボタン・後ろのゲーム画面を暗くするか）
- PC のキー（Esc・P など）で止めるか
- 自動で止まるとき：アプリ・タブが隠れたとき（visibilitychange）。今は戻った瞬間に動き出す（`src/app/loop.ts`）
- ウェーブのあいだ・終わりの表示のあいだに止められるか
- 「やめてタイトルへ」で、そのプレイを TOP10 に入れるか
- 作らない：アプリを閉じたあとの続き（LLM-PG-0002）
