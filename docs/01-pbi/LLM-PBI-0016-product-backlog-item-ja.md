# LLM-PBI-0016 遊んでいる途中で止め、続きから遊べる（ボタンと、アプリを離れたとき）

依頼：2026-11-19 13:44 ごろ（PO が次のプロダクトゴールの中心に選んだ。LLM-PG-0002 の案 B は 13:46 ごろ）。2026-11-20 のスプリント 16 のリファインメントで整理した

## ストーリー

すき間時間に遊ぶオーナーとして、途中で手が離れても（自分で止めたとき・電話や通知でアプリを離れたとき）、戻って「続ける」を押すまでゲームが進まず、止めたところから続けたい。なぜなら、今は戻った瞬間に動き出し、気づく前に都市がやられてしまうから。

## 受け入れ条件

| 確認 ID | 条件 |
| :--- | :--- |
| LLM-TC-0016-01 | プレイ中（ウェーブのあいだの「WAVE n」の表示を含む）は、HUD の `1P` と `TOP` のあいだに止めるボタン「II」を出す（x 210〜270・y 0〜60、論理）。触る／クリックすると止めた画面になる。ボタンを触っても弾は撃たない。終わり（CLEAR・GAME OVER）の表示が出たらボタンを消し、止められない。タイトル・TOP10・名前の入力・クレジットの画面には出さない |
| LLM-TC-0016-02 | 止めた画面：後ろのゲーム画面を暗くし、「PAUSE」「止めています」と「▶ 続ける」「やめてタイトルへ」のボタンを出す。止めているあいだはゲームが 1 ステップも進まない（敵・空の敵・爆風・ウェーブの表示の時間・点・残弾が変わらない）。BGM も止まる。ボタンの外を触る／クリックしても弾を撃たない |
| LLM-TC-0016-03 | 「▶ 続ける」を触る／クリック、または Esc・P を押すと、止めたところから続く（止める前と同じ状態から進む）。BGM が鳴り直す。続けた操作で弾を撃たない |
| LLM-TC-0016-04 | PC では、プレイ中に Esc・P を押しても止まる（ボタンと同じ止めた画面） |
| LLM-TC-0016-05 | アプリ・タブが隠れたら（`visibilitychange` で `hidden`）、止めた画面にする。戻っても止まったままで、「続ける」を押すまで進まない。終わりの表示のあいだ・ほかの画面では何もしない（今までどおり） |
| LLM-TC-0016-06 | 「やめてタイトルへ」を触る／クリックすると、そのプレイを TOP10 に入れず（保存も変えず）にタイトル画面に戻る。タイトルから始めると新しい WAVE 1 になる |
| LLM-TC-0016-07 | PC の Chrome と iPhone 11（ホーム画面のプレビューのアプリ）で、止めて続ける・「やめてタイトルへ」、iPhone ではホーム画面に戻ってアプリを離れ、開き直すと止まっていて「続ける」で続けられる。iPhone 11 の `?debug=1` で fps 55 以上。実機は 1 回（違いの細かい確かめは E2E で。案 28） |

## 範囲に入れないもの

- アプリを閉じた・iPhone がアプリを終わらせたあとに、続きから遊ぶこと（ゲームの状態の保存。案 C は選ばなかった）
- 終わりの表示・ほかの画面で止めること（PO の決定：止められない）
- 途中でやめたプレイを TOP10 に入れること（PO の決定：入れない）

## メモ

- 2026-11-20 の PO の決定（スプリント 16 のリファインメント）：決めること 1〜6 を表の案のとおり（10:32:38 ごろ）
- 案 25 の点検（2026-11-20 10:33）：`visibilitychange` は E2E の端末（pc-chromium・iphone11-webkit）のどちらにもある。ただし、ヘッドレスでは別のタブを前に出しても `hidden` にならない → E2E は `document.visibilityState` を上書きしてイベントを出す「まね」で確かめる（両方の端末で働いた）。本物のアプリを離れるのは実機（LLM-TC-0016-07）で 1 回
- 開発者の決め：止めているかはアプリの層（`src/main.ts` の画面の状態）で持ち、止めているあいだは `advanceBy` でゲームを進めない。ゲームのロジック（`src/core`）は変えない。止めた画面とボタンは「クレジット」と同じ HTML の部品（`src/app/pause.ts` の見込み）。`?debug=1` の `freeze` とは別
- 大きさ：S（1 TASK）
