# LLM-PBI-0002 iPhone のタッチで迎え撃てる

## ストーリー

iPhone で遊ぶ人として、ゲーム画面の狙いたい所を指で触るだけで迎撃ミサイルを撃ちたい。それは、PC がなくても、すき間時間に片手でも遊べるようにするため。

## 受け入れ条件

| 確認 ID | 条件 |
| :--- | :--- |
| LLM-TC-0002-01 | ゲーム画面を指で触ると、触った所へ、横の距離がいちばん近い基地（残弾のあるもの）から迎撃ミサイルが飛ぶ。照準も触った所に移る |
| LLM-TC-0002-02 | 横の距離が同じ基地が 2 つあるときは、中央の基地 B を先に、A と C なら A を選ぶ。残弾 0 の基地は飛ばして次に近い基地から撃つ。3 つとも 0 なら何も起きない |
| LLM-TC-0002-03 | 1 回触ると 1 発だけ撃つ（触ったまま指をすべらせても撃たない）。2 本の指でほぼ同時に触ると、それぞれの場所へ 1 発ずつ撃つ |
| LLM-TC-0002-04 | iPhone 11 と iPhone SE（第 3 世代）の縦の画面で、ゲーム画面の全体（HUD・基地・残弾）が欠けずに 1 画面に収まる。ノッチ・ホームバーに重ならない |
| LLM-TC-0002-05 | 長押しの虫めがね・メニュー、2 回タップの拡大、2 本指の拡大、画面のスクロール・引っぱりが起きない |
| LLM-TC-0002-06 | PC の操作は LLM-PBI-0001 のまま（マウスのクリックでは撃たない） |
| LLM-TC-0002-07 | iPhone 11 の Safari でプレビューの URL を開くと遊べ、画面の版の表示が main の版と同じ。ホーム画面に置いたプレビュー版でも遊べる |

## 画面

LLM-GUI-0002（プレイ画面・iPhone のタッチ）

## 範囲に入れないもの

- 発射ボタン・操作空間（案 A・B）は作らない（PO が案 C に決めたため）
- 横向きの画面の作り込み（縦長のまま小さく出る。左右は黒）
- iPad・Android の確認（IDK Q4）
- 一時停止 → LLM-PBI-0016（あとで決める）

## メモ

- 2026-11-04：PO が iPhone 11 で試作（`prototype/touch-controls/`）の案 A・B・C を触り、**案 C**（触った所へ、いちばん近い残弾のある基地からすぐ撃つ）に決めた。試作では長押しの虫めがね・2 回タップの拡大は出なかった。これで IDK 7a-6 が決まった。
- 仕様書 §3.2 は「基地 A・B・C に対応する発射ボタン」だが、タッチでは基地を自動で選ぶ。基地を選ぶ駆け引きはタッチでは小さくなる（PC では残る）。PO が承知のうえで決めた。
- 「近い」は横の距離（x）で比べる（基地はどれも同じ高さにあるため。試作と同じ）。
- 照準の慣性はタッチでは使わない。
- 大きさ：発射ボタン・操作空間がなくなったので M → **S** の案。
- 完成の定義の「iPhone 11 で fps 55 以上」はこの PBI から確かめる。
