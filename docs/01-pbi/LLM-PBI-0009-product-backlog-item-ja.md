# LLM-PBI-0009 爆撃機と衛星が横切ってミサイルを落とす

状態：未整理（リファインメントで、受け入れ条件・確認 ID・画面を足す）

## ストーリー

遊ぶ人として、空を横切る敵を狙って高い点を取りたい。それは、ミサイルを落とすか元を断つかの駆け引きが生まれるから。

## メモ（仕様書から・決めること）

- 爆撃機：画面の上のほうを左右に横切り、真下にミサイルを落とす（100 点）
- 衛星：上空を横切り、ときどき弾頭を落とす（100 点）
- 見た目は独自のドット絵にする
