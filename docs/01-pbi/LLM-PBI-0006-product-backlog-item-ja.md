# LLM-PBI-0006 タイトル画面で TOP10 を見て始められる（保存・ランクイン判定）

## ストーリー

遊ぶ人として、タイトル画面で今の TOP10 を見てから始め、終わったら自分の点が入ったかを見たい。それは、ランキングに入ることが遊ぶ目標になるから。

## 受け入れ条件

| 確認 ID | 条件 |
| :--- | :--- |
| LLM-TC-0006-01 | 開くとタイトル画面になり、`LAST LINE MINI` と TOP10（順位・名前・点の 10 行）が出る。記録のない行は `---  000000`。触るか押すと WAVE 1 から始まる |
| LLM-TC-0006-02 | 終わった点を TOP10 に入れ、点の高い順に 10 件まで残す。11 位になったものは消える。同じ点は先に取ったほうが上。10 位と同じ点は入らない。10 件より少ないときは必ず入る |
| LLM-TC-0006-03 | 保存のキーがプレビューと本番で分かれている。保存の中身が壊れていても起動し、TOP10 は空になる |
| LLM-TC-0006-04 | 終わりの画面で触るか押すと TOP10 の画面になり、今回の点（`YOUR SCORE`）が出る。ランクインしたら今回の点が TOP10 に入っている。TOP10 の画面で触るか押すとタイトル画面に戻る |
| LLM-TC-0006-05 | HUD の `TOP` に TOP10 の 1 位の点が出る（記録がなければ `000000`） |
| LLM-TC-0006-06 | ページを開き直しても TOP10 が残っている |
| LLM-TC-0006-07 | PC の Chrome と iPhone 11 のプレビューで、タイトル → プレイ → 終わり → TOP10 → タイトルを通して遊べ、開き直しても TOP10 が残る（右下の番号がマージのコミットと同じ） |

## 画面

LLM-GUI-0003（タイトル・TOP10）、LLM-GUI-0001 §1（HUD の TOP）・§5（終わりのあと）。

## 範囲に入れないもの（あとの PBI）

- 名前の入力・今回の行の点滅 → LLM-PBI-0007（それまでは、ランクインした記録の名前を `...` にする）
- ランキングの書き出し・読み込み → LLM-PBI-0018（あとで決める）
- オンラインのランキング（やらない）

## メモ

- 2026-11-09 の PO の決定（スプリント 06 のプランニングのリファインメント）：
  - 10 位と同じ点（7a-4）：**同点は入らない**（仕様書 §5.1・§5.3 どおり）
  - 画面の流れ：**TOP10 の画面をタイトルとは別に置く**（終わり →〔名前〕→ TOP10 → タイトル → WAVE 1）
- 作りの案：
  - TOP10 は端末の中（localStorage）に 10 件だけ。記録の形は仕様書 §5.2（名前・点・残った都市・残弾・CLEAR か GAME OVER・日時。順位は並びから出す）
  - 保存のキーは LLM-SA-0001 §2 のとおり、本番 `last-line-mini-ranking`・プレビュー `last-line-mini-preview-ranking`
- 大きさ：M（2 TASK）
