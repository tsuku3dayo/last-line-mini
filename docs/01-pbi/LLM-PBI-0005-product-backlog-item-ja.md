# LLM-PBI-0005 点数が HUD に出て、終わりにボーナスが足される

## ストーリー

遊ぶ人として、今の点数を見ながら遊び、終わりに残した弾と都市の分が足されるのを見たい。それは、点を伸ばす工夫が見えるから。

## 受け入れ条件

| 確認 ID | 条件 |
| :--- | :--- |
| LLM-TC-0005-01 | 迎撃でも誘爆でも、敵を 1 つ壊すと 25 点が入り、HUD の `1P` に 6 桁で出る。地面に落ちた敵は 0 点 |
| LLM-TC-0005-02 | 終わり（CLEAR・GAME OVER）に、残弾 × 5 と残った都市 × 100 が足され、`1P` が最終スコアになる。壊れた基地の残弾は 0 として数える |
| LLM-TC-0005-03 | 終わりの画面に、ボーナスの内訳が 2 行（MISSILES・CITIES）で出る |
| LLM-TC-0005-04 | やり直すと `1P` は 0 から始まる。`TOP` は `000000` のまま（LLM-PBI-0006 まで） |
| LLM-TC-0005-05 | 照準の始めの位置が (240, 420) で、「WAVE 1」の文字と重ならない |
| LLM-TC-0005-06 | PC の Chrome と iPhone 11 のプレビューで、点数とボーナスを見ながら 1 プレイ遊べる（右下の番号がマージのコミットと同じ） |

## 画面

LLM-GUI-0001 §1（HUD）・§5（終わりの表示・照準の始めの位置）。iPhone も同じ（LLM-GUI-0002）。

## 範囲に入れないもの（あとの PBI）

- TOP の数字（TOP 10 の 1 位）・保存 → LLM-PBI-0006
- 多弾頭・爆撃機・衛星・スマートミサイルの点 → それぞれの敵の PBI（0008・0009・0010）
- 点の開き方・難しさの調整 → LLM-PBI-0011

## メモ

- 2026-11-05 の PO の決定（スプリント 05 のプランニングの前のリファインメント）：
  - HUD の TOP：**0 のまま**（PBI-0006 まで `TOP 000000`）
  - 照準と「WAVE 1」の重なり（スプリント 04 のレトロの案 2）：**始めの位置を下げる**（(240, 300) → (240, 420)）
- 作りの案：
  - 点は仕様書 §4.1 のとおり、アタックミサイル 25 点。誘爆で壊れた敵も 25 点
  - 残弾ボーナスは、終わった時点の各基地の残弾で数える（ウェーブごとに 10 発に戻るので、最後のウェーブで残った弾。GAME OVER のときはその時点の弾）
  - 内訳とボーナスを足した点は、終わった瞬間に出す（数え上げの動きは付けない）
- 大きさ：S（2 TASK）
