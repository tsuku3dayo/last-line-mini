# LLM-PBI-0020 名前に日本語も使え、8 文字まで入れられる

## ストーリー

家族や友だちと 1 台で遊ぶ人として、TOP10 にふだんの呼び名（日本語）を 8 文字まで残したい。それは、英字 3 文字では誰の記録か分かりにくく、自分だと分かる名前で比べたいから（PO の答え、2026-11-09）。

## 受け入れ条件

| 確認 ID | 条件 |
| :--- | :--- |
| LLM-TC-0020-01 | 使える文字は、ひらがな・カタカナ・漢字・英字（大文字も小文字もそのまま）・数字（半角・全角）・記号。絵文字・空白・そのほかの文字は入らない（打っても消える） |
| LLM-TC-0020-02 | 8 文字まで入る。見た目の 1 文字を 1 文字と数える（半角も全角も 1 文字）。9 文字目は入らない。空のまま確定すると名前は `...` |
| LLM-TC-0020-03 | 日本語入力の変換中（確定する前）は、打った文字が消えず、Enter は変換の確定にだけ使う（名前は確定しない）。変換を確定したあとの Enter・`OK` で名前を確定する |
| LLM-TC-0020-04 | タイトルと TOP10 の画面で、名前がブラウザの文字で描かれる。全角 8 文字の名前でも 1 行が画面に収まり、順位・名前・点の列がそろう。今回の行は名前も点と一緒に点滅する |
| LLM-TC-0020-05 | 今までの記録（英字 3 文字・`...`）は、そのまま読めて出る。新しい名前の記録も、読み込み直したあとに同じ名前で出る |
| LLM-TC-0020-06 | PC の Chrome と iPhone 11 のプレビューで、日本語入力で 8 文字の名前を入れて TOP10 に出せる（右下の番号が最後のコードの PR のマージと同じ） |

## 画面

LLM-GUI-0003 §1〜§3（v1.1）。

## 範囲に入れないもの

- 方向キーで文字を選ぶ入れ方（仕様書 §5.1。LLM-PBI-0007 のとおり作らない）
- 名前の重なりの確かめ・言葉の検査（よくない言葉を止めるなど）
- ランキングの書き出し・読み込み（LLM-PBI-0018）

## メモ

- 2026-11-09 のスプリント 06 のレビューで PO が依頼：「名前入力：名前を日本語OK・最大8文字にする」
- 2026-11-12 の PO の決定（スプリント 09 のプランニングのリファインメント、11:07:24）：使える文字は「日本語＋英数字＋記号（絵文字なし）」
- 仕様書 §5.1（A〜Z・0〜9・. の 3 文字）・§5.2（`player_name` String(3)）を変える → 仕様書 v1.2
- 開発者の決め：
  - 8 文字は見た目の 1 文字（書記素）で数える（`Intl.Segmenter`。iPhone 11 の Safari でも使える）
  - 自前の 5 × 7 ドットの文字は英数字だけなので、名前だけブラウザの文字（ゴシック）で描く
  - 入力欄の整え（使えない文字を消す・8 文字に切る）は、変換中はせず、変換の確定のあとにする（今のままだと変換が壊れる）
  - 保存の形の検査を新しい決まりに広げる。今までの記録は新しい決まりにも合うので、そのまま読める
- 大きさ：S（1 TASK）

## 変更の影響の一覧（TEAM 4.6）

依存するコードとテストは grep（`NAME_LENGTH`・`sanitizeName`・`finalName`・`A-Z0-9`・`padEnd(3)`・`name-input`・`EMPTY_NAME`、文書は「3 文字」・§5.1・§5.2）で洗い出した。
