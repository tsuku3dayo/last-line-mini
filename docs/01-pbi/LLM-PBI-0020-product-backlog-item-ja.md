# LLM-PBI-0020 名前に日本語も使え、8 文字まで入れられる

状態：未整理（リファインメントで、受け入れ条件・確認 ID・画面を足す）

## ストーリー

家族や友だちと 1 台で遊ぶ人として、TOP10 にふだんの呼び名（日本語）を 8 文字まで残したい。それは、英字 3 文字では誰の記録か分かりにくく、自分だと分かる名前で比べたいから（PO の答え、2026-11-09）。

## メモ（PO の依頼・決めること）

- 2026-11-09 のスプリント 06 のレビューで PO が依頼：「名前入力：名前を日本語OK・最大8文字にする」
- 仕様書 §5.1（A〜Z・0〜9・. の 3 文字）・§5.2（`player_name` String(3)）を変える → 仕様書の版を上げ、PO の承認
- 決めること（リファインメント）：
  - 使える文字（ひらがな・カタカナ・漢字・英数字・記号・絵文字のどこまでか）。「8 文字」の数え方（絵文字・結合文字）
  - TOP10・名前の画面での描き方：自前の 5 × 7 ドットの文字は英数字だけなので、名前だけブラウザの文字で描くか
  - 今までの `...` や英字 3 文字の記録はそのまま使えるか（保存の形の検査を広げる）
- 作りで気をつけること：iPhone・PC の日本語入力の変換中（確定前）の Enter で確定しない。8 文字の名前でも TOP10 の 1 行が画面の幅に収まるか（全角 8 文字で約 336 ドットの見込み）
- 変更の影響（TEAM 4.6。リファインメントで確かめる）：仕様書 §5.1・§5.2、LLM-PBI-0007 の受け入れ条件（TC-0007-02）、LLM-GUI-0003 §1〜§3、`src/core/name.ts`・`src/storage/ranking-store.ts`・`src/render/screens.ts`、TC-0006・0007 の E2E
