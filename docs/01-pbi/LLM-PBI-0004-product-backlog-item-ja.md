# LLM-PBI-0004 1 面がウェーブで進み、CLEAR か GAME OVER で終わる

## ストーリー

遊ぶ人として、攻撃の波を凌ぎ切ったら「守り切った」、守れなかったら「終わり」とはっきり分かりたい。それは、1 面完結の 1 プレイとして終わりがあるから。

## 受け入れ条件

| 確認 ID | 条件 |
| :--- | :--- |
| LLM-TC-0004-01 | 始めると「WAVE 1」が出て、敵が決まった数だけ落ちてくる。ウェーブは 4 つで、ウェーブごとに敵が増える（仮の数：6・9・12・15） |
| LLM-TC-0004-02 | ウェーブの敵がすべて消える（落とす・地面に着く）と、約 3 秒「WAVE n」が出て、壊れていない基地の弾が 10 発に戻り、次のウェーブが始まる。壊れた基地は戻らない |
| LLM-TC-0004-03 | 最後のウェーブの敵がすべて消えたとき、都市が 1 つ以上残っていれば CLEAR になり、「DEFENSE COMPLETE」が出る |
| LLM-TC-0004-04 | 6 都市がすべて壊れた瞬間に GAME OVER になり、「THE END」が出る |
| LLM-TC-0004-05 | 壊れていない基地の弾がすべて 0 で、飛んでいる迎撃ミサイルと爆風もなく、残っている都市を狙う敵が飛んでいる時点で、GAME OVER になる |
| LLM-TC-0004-06 | 終わりの演出の約 1 秒あとに「TAP OR PRESS ANY KEY」が出て、画面を触るかキーを押すと、最初のウェーブから始まる（それより前の操作は受け付けない） |
| LLM-TC-0004-07 | PC の Chrome と iPhone 11 のプレビューで、1 プレイを最後まで遊べる（約 3 分。右下の番号がマージのコミットと同じ） |

## 画面

LLM-GUI-0001 §5（ウェーブと終わりの表示）。iPhone も同じ（LLM-GUI-0002）。

## 範囲に入れないもの（あとの PBI）

- 点数・終わりのボーナス → LLM-PBI-0005
- タイトル画面・TOP10 → LLM-PBI-0006（それまでは、開くとすぐ WAVE 1 が始まり、終わったら触るか押すと最初から）
- 多弾頭ミサイル → LLM-PBI-0008
- ウェーブの数・敵の数・速さの調整 → LLM-PBI-0011

## メモ

- 2026-11-04 の PO の決定（スプリント 04 のプランニングの前のリファインメント）：
  - 7a-1：**4 ウェーブ・約 3 分**（数は仮。PBI-0011 で直す）
  - 弾の補充：**ウェーブごとに 10 発に戻す**（壊れた基地は戻さない）。仕様書には「各基地 10 発を初期装填」とだけあり、補充が書かれていなかった。残弾ボーナス（PBI-0005）は最後のウェーブで残った弾で数える
  - 7a-2：**B「止められなくなったら」**：弾が 0・飛んでいる迎撃と爆風がない・残っている都市を狙う敵が飛んでいる、がそろった時点で GAME OVER（仕様書「全拠点の弾薬が尽きて着弾を阻止できなくなった時点」の読み）
  - 終わったあと：**触るか押すと最初から**
- 作りの案：
  - ウェーブのあいだ（約 3 秒）は敵が出ない。迎撃ミサイルは撃てる（残りの爆風で遊べる）
  - GAME OVER になったら、その場でゲームを止めて演出を出す。CLEAR のときは画面に敵が残っていない
  - 7a-2 の「都市を狙う敵」は、今飛んでいる敵だけで判定する（まだ出ていない敵の狙いは乱数で決まるため）。弾は次のウェーブで戻るので、ウェーブのあいだは判定しない
  - 最初からやり直すときは、新しい乱数の種で始める（`?debug=1&seed=` のときは同じ種）
- 大きさ：M（3〜4 TASK）
