# LLM-PBI-0008 多弾頭ミサイルが途中で分かれる

## ストーリー

遊ぶ人として、途中で分かれるミサイルに慌てたい。それは、早めに落とす判断が生まれるから。

## 受け入れ条件

| 確認 ID | 条件 |
| :--- | :--- |
| LLM-TC-0008-01 | WAVE 1 は通常の弾だけ。WAVE 2〜4 では、そのウェーブの敵のうち 3・4・5 発（約 3 分の 1）が多弾頭になる |
| LLM-TC-0008-02 | 多弾頭は、画面の上から 4〜6 割の高さのどこか（毎回、乱数）で、2〜3 発（乱数）の子の弾に分かれる。子の弾はそれぞれ別の都市・基地を狙い、速さは親と同じ |
| LLM-TC-0008-03 | 分かれる前に爆風（迎撃・誘爆）で落とすと 25 点で、子の弾は出ない。分かれたあとは子の弾 1 発ごとに 25 点。子の弾も誘爆し、着くと都市・基地を壊す |
| LLM-TC-0008-04 | 分かれるまでは通常の弾と同じ見た目。分かれた点から子の航跡が伸び、親の航跡（上から分かれた点まで）は子の弾があるあいだ残る |
| LLM-TC-0008-05 | ウェーブの敵の数は親で数える（6・9・12・15 のまま）。子の弾がすべて消えるまでウェーブは終わらない。弾切れで止められないかの判定（LLM-TC-0004-05）に、分かれる前の多弾頭の子の狙いも入る |
| LLM-TC-0008-06 | PC の Chrome と iPhone 11 のプレビューで、多弾頭が分かれ、分かれる前にも分かれたあとにも落とせる（右下の番号が最後のコードの PR のマージと同じ） |

## 画面

LLM-GUI-0001 §4（多弾頭が分かれる。v1.8）。iPhone は LLM-GUI-0002 のまま。

## 範囲に入れないもの

- 多弾頭の数・高さ・分かれる数の調整（LLM-PBI-0011 で、数は config の値にしておく）
- 爆撃機・衛星・スマートミサイル（LLM-PBI-0009・0010）

## メモ

- 仕様書 §4.1：降りる途中で複数の子弾頭に分かれる。見た目では通常弾と見分けられない。点数は各弾頭 25
- 2026-11-10 の PO の決定（スプリント 08 のプランニングのリファインメント、17:10:35）：決めること 1〜5 を表の案のとおり（WAVE 2 から約 3 分の 1・上から 4〜6 割で分かれる・2〜3 発・分かれる前は 25 点・ウェーブは親で数える）。仕様書が決めていないところを決めたもので、仕様書とは食い違わない
- 子の弾の狙いは、親が出たときに決めておく（LLM-TC-0004-05 の判定で数えられるように。開発者の決め）
- 大きさ：S（1 TASK）
