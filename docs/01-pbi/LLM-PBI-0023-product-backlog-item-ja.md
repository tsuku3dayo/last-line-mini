# LLM-PBI-0023 タイトル画面で、プレイ中とは別の BGM が鳴る

状態：未整理（LLM-PG-0004 の範囲。スプリント 18 のリファインメントで受け入れ条件・確認 ID・決めることを足す）
依頼：2026-11-20 14:29 ごろ（PO：「追加の要望です。タイトル画面にBGMを追加してください。」）

## ストーリー

遊ぶオーナーとして、タイトル画面でもプレイ中とは別の BGM を聞きたい。なぜなら、無音のタイトルでは遊ぶ前の雰囲気が伝わらず、タイトルとプレイで曲が切り替われば始まった・戻ったが耳で分かり、「♪ 音 ON／OFF」を押したときに音が出るかもすぐ確かめられるから。

## メモ（決めること）

- 曲の感じ：プレイ中の曲（短調・16 音・120〜152 拍）と聞き分けられること。ゆっくり・静かめか、勇ましく・期待させるか。長さ（何音でくり返すか）
- 鳴らす画面：タイトルだけか、クレジット・TOP10 の名前入れ・終わりの画面でも鳴らすか
- 鳴り始め：ブラウザは最初に画面に触るまで音を出せない。最初の 1 回目は、タイトルのどこかに触ったら鳴らすか（触っても始まらない場所を作る）、「はじめる」を押すまで鳴らさないか
- 切り替え：タイトル → プレイでタイトルの曲を止めてプレイの曲へ。プレイ → 終わり → タイトルで戻す。重ならないこと
- 「♪ 音 ON／OFF」：OFF のときは鳴らさない。タイトルで ON にしたらすぐ鳴る
- 音量：プレイ中の BGM と同じくらいか小さめ（効果音より小さく）
- 今の仕組み（`src/app/bgm.ts` の Web Audio の合成）を使い、新しいブラウザの仕組みは使わない見込み（案 25 の点検は「なし」の見込み）。E2E は今と同じく `data-bgm` で鳴らす判断を読む
- 大きさ：S の見込み
