# LLM-PBI-0023 タイトル画面で、プレイ中とは別の BGM が鳴る

依頼：2026-11-20 14:29 ごろ（PO：「追加の要望です。タイトル画面にBGMを追加してください。」）。2026-11-20 のスプリント 18 のリファインメントで整理した

## ストーリー

遊ぶオーナーとして、タイトル画面でもプレイ中とは別の BGM を聞きたい。なぜなら、無音のタイトルでは遊ぶ前の雰囲気が伝わらず、タイトルとプレイで曲が切り替われば始まった・戻ったが耳で分かり、「♪ 音 ON／OFF」を押したときに音が出るかもすぐ確かめられるから。

## 受け入れ条件

| 確認 ID | 条件 |
| :--- | :--- |
| LLM-TC-0023-01 | タイトル画面とクレジット画面で、タイトルの曲が鳴る：短調・ゆっくり（90 拍）・プレイ中の曲より低め・32 音をくり返す。音色と音量はプレイ中の BGM と同じ（三角波・合成）。タイトル ⇄ クレジットの行き来では曲を止めない。名前を入れる画面・TOP10 の画面では鳴らさない |
| LLM-TC-0023-02 | 切り替え：タイトルから始めるとタイトルの曲が止まり、プレイの曲（120〜152 拍、今までどおり）になる。2 つの曲は重ならない。終わり（CLEAR・GAME OVER）・止めた画面では今までどおり鳴らさない。タイトルに戻ると、タイトルの曲を最初から鳴らす |
| LLM-TC-0023-03 | 「♪ 音 ON／OFF」が OFF のときは鳴らさない。タイトルで ON にすると、その場で鳴り始める。アプリを開いて最初に触るまでは鳴らない（ブラウザの決まり）。最初に触ったときにゲームが始まる今の動きは変えない（タイトルの曲は、ボタンを触ったときと、遊んで戻ったときから聞こえる） |
| LLM-TC-0023-04 | PC の Chrome と iPhone 11（ホーム画面のプレビューのアプリ）で、タイトル（「♪ 音 ON／OFF」を押す、または 1 回遊んで戻る）で曲が鳴る・プレイで曲が切り替わる・タイトルに戻るとタイトルの曲になる・OFF で鳴らない。プレイの曲と聞き分けられ、うるさすぎない。iPhone 11 の `?debug=1` で fps 55 以上。実機は 1 回ずつ（案 28） |

## 画面

見た目は変わらない（LLM-GUI-0003 はそのまま。モックなし）。

## 範囲に入れないもの

- 開いて最初の 1 回目だけ、触っても始めずに音を出す動き（PO の決定：今の動きのまま）
- 名前を入れる画面・TOP10 の画面の曲、ウェーブごとのメロディ、音量を選ぶ設定の画面
- 音のファイル（Web Audio の合成のまま）

## メモ

- 2026-11-20 の PO の決定（スプリント 18 のリファインメント）：決めること 1〜6 を案のとおり（曲・鳴らす画面・切り替え・ON／OFF・音量・合成でモックなし）、最初の 1 回目は「今の動きのまま」
- 開発者の決め：`src/app/bgm.ts` に曲を 2 つ持たせ、画面と状態からどちらを鳴らすか（なし・タイトル・プレイ）を決める純粋な関数にする。曲が変わったら最初の音から予約し直す（重ならない）。E2E が読む `data-bgm` は、プレイは今までどおり `on:<拍>`、タイトルの曲は `title:90`、鳴らさないときは `off`
- 新しいブラウザの仕組みは使わない（今の Web Audio の合成。案 25 の点検は「使わない」）
- 大きさ：S（1 TASK）
