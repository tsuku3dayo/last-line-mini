# LLM-PBI-0014 効果音と BGM が鳴る

依頼：2026-11-02（インセプションデッキの「あとで決める」から。時刻なし）。2026-11-19 13:55 ごろ PO が 2 番目に上げた

## ストーリー

遊ぶ人として、撃つ・爆発する・都市がやられる音と BGM を聞きながら遊びたい。それは、手応えが増し、画面の上の空の敵にも音で気づけるから。

## 受け入れ条件

| 確認 ID | 条件 |
| :--- | :--- |
| LLM-TC-0014-01 | 効果音が 8 種鳴る：撃つ・爆発（迎撃と誘爆）・都市や基地がやられる・爆撃機や衛星が出る・爆撃機や衛星を壊す・ウェーブの始め・CLEAR／GAME OVER・ランクイン。同じステップにいくつ起きても、同じ音は 1 回だけ鳴らす |
| LLM-TC-0014-02 | BGM はプレイ中だけ、短いメロディをくり返す。後半のウェーブほど少し速い。終わり（CLEAR・GAME OVER）で止まり、タイトル・TOP10・名前の入力・クレジットでは鳴らない |
| LLM-TC-0014-03 | 音は Web Audio の合成で作る（音のファイルを使わない。公開する版に音のファイルが入っていない） |
| LLM-TC-0014-04 | タイトル画面の「♪ 音 ON／OFF」ボタン（LLM-GUI-0003 v1.4 §8）を触る／クリックすると切り替わり、OFF のときは効果音も BGM も鳴らない。選んだ方は端末に覚え、開き直しても同じ。初めは ON。ボタンを触ってもゲームは始まらない |
| LLM-TC-0014-05 | 音は最初に触った・クリックした・キーを押したときから出せるようにする（iPhone は触るまで音を出せない）。それより前は鳴らさず、エラーにならない |
| LLM-TC-0014-06 | PC の Chrome と iPhone 11 のプレビューで、効果音と BGM が鳴り、ON／OFF が効く。うるさすぎない。iPhone 11 の `?debug=1` で fps 55 以上 |

## 画面

LLM-GUI-0003 §1・§8（「♪ 音 ON／OFF」ボタン。v1.4）。モック：`scratchpad/mock/sound-mock.png`（2026-11-19 にスプリント 14 のリファインメントで PO に見せた。リポジトリには入れない）。

## 範囲に入れないもの

- 音量の細かい調整（大きさのつまみ）。ON／OFF だけ
- 音のファイル（mp3 など）・外の素材
- iPhone のマナーモードのときに鳴らすこと（端末の決まりで鳴らないことがある。README に書く）

## メモ

- 2026-11-19 の PO の決定（スプリント 14 のリファインメント）：決めること 1〜6 を表の案のとおり（15:28:14 前）
- 開発者の決め：音は app 層に置き（`src/app/audio.ts`）、core は変えない。鳴らす時は、1 ステップ前と後の状態の違い（迎撃が増えた・爆風が出た・都市が減った・空の敵が出た／壊れた・ウェーブの状態が変わった）から決める。E2E は `?debug=1` で鳴らした音の名前を数えて確かめる（音そのものは実機で聞く）
- 大きさ：M（2 TASK の見込み：音の仕組みと効果音 → BGM と ON／OFF のボタン）
