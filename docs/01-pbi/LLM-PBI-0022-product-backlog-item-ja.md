# LLM-PBI-0022 ランキング（TOP10）のデータを消して、最初からにできる

依頼：2026-11-20 10:24 ごろ（PO：「PBI-0018 は削除します。新たにランキングデータのクリアを追加します。」）。2026-11-20 のスプリント 17 のリファインメントで整理した

## ストーリー

遊ぶオーナーとして、端末に残っている TOP10 の記録を消して、最初からにしたい。なぜなら、試しに遊んだ記録や古い記録が残ったままだと、新しく競い直せないから。

## 受け入れ条件

| 確認 ID | 条件 |
| :--- | :--- |
| LLM-TC-0022-01 | タイトル画面の右下（「クレジット」の右、x 336〜456・y 560〜620、論理）に「記録を消す」（赤い枠）を出す。記録が 1 件もないときは出さない。ほかの画面には出さない。押してもゲームは始まらない。タイトルが出てから約 1 秒は受け付けない |
| LLM-TC-0022-02 | 「記録を消す」を押すと、確かめる画面になる：「TOP10 の記録を消しますか？」・「この端末の記録（n 件）をすべて消します。消した記録は元に戻せません。」・「消す」（赤）・「やめる」。画面が出てから約 1 秒は押せない |
| LLM-TC-0022-03 | 「やめる」（PC は Esc でも）で、何も消さずにタイトルに戻る。ボタンの外を触る・ほかのキーでは何もしない（ゲームは始まらない） |
| LLM-TC-0022-04 | 「消す」で、開いているチャンネル（本番かプレビュー）の TOP10 の保存だけを消し、タイトルに戻る。TOP10 はすべて `---`・`000000`、HUD の `TOP` は `000000`、「記録を消す」は消える。音の ON／OFF の保存と、もう一方のチャンネルの記録は残る。開き直しても空のまま |
| LLM-TC-0022-05 | 消したあと遊んでランクインすると、今までどおり名前を入れて 1 位に入る |
| LLM-TC-0022-06 | PC の Chrome と iPhone 11（ホーム画面のプレビューのアプリ）で、確かめる画面で「やめる」→ 記録が残る、「消す」→ TOP10 が空になり開き直しても空。iPhone 11 の `?debug=1` で fps 55 以上。実機は 1 回ずつ（案 28） |

## 画面

LLM-GUI-0003 v1.6 §10（「記録を消す」のボタンと確かめる画面）と §1（タイトルの配置）・§0（画面の流れ）。モック：`scratchpad/mock/clear-mock.png`（2026-11-20 のスプリント 17 のリファインメントで PO に見せた。下絵は main d73e350 のタイトル画面）。

## 範囲に入れないもの

- TOP10 の画面・クレジットから消すこと（PO の決定：入口はタイトルだけ）
- 1 件ずつ消すこと、消した記録を戻すこと
- 音の ON／OFF の保存を消すこと（PO の決定：残す）
- 書き出し・読み込み（PBI-0018 は 2026-11-20 に PO が削除）
