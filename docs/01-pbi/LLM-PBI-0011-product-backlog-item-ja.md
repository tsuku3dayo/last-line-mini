# LLM-PBI-0011 難しさを調整し、1 プレイ 3 分前後で後半ほど難しくする

## ストーリー

すき間時間に遊ぶ人として、今より少し長く、後半ほど手ごたえが増し、爆風でまとめて落とす気持ちよさのある 1 プレイを遊びたい。それは、くり返し遊んで TOP10 を目指す理由になるから。

## 受け入れ条件

| 確認 ID | 条件 |
| :--- | :--- |
| LLM-TC-0011-01 | ウェーブは 5 つ。ウェーブが進むほど敵の数が増え、5 ウェーブ目の敵がすべて消えて都市が残っていれば CLEAR。敵の攻撃は v1.0 の 1.5 倍：敵の数（多弾頭の数も）を 1.5 倍、出る間隔を 1/1.5 にして、同じ時間に来る敵を 1.5 倍にする（v1.1） |
| LLM-TC-0011-02 | 後半ほど難しい：ウェーブが進むほど、敵の落ちる速さが上がり、出る間隔が短くなる（どちらも前のウェーブより下がらない・長くならない） |
| LLM-TC-0011-03 | 守り切ったときの長さの目安が 2 分半〜3 分半：各ウェーブの最後の敵を画面の半ばの高さで落とすとして、設定値から計算した 1 プレイの長さが 150〜210 秒 |
| LLM-TC-0011-04 | 多弾頭がウェーブの何発目に出るかは、乱数の種から決まる。数はウェーブごとに決まった数、同じ種なら同じ順番、多弾頭が 2 発続けては出ない。WAVE 1 は多弾頭なし |
| LLM-TC-0011-05 | 爆風（迎撃・誘爆とも）の最大の半径が今の 1.5 倍（24 → 36）。最大になってから 0.5 秒そのまま残り（v1.1。v1.0 は 1 秒）、そのあと縮んで消える（広がる 0.4 秒・縮む 0.5 秒は今のまま） |
| LLM-TC-0011-06 | PC の Chrome と iPhone 11 のプレビューで、PO が守り切ったときの長さが 2 分半〜3 分半、後半ほど難しく感じ、爆風が大きく少し長く残る。iPhone 11 の `?debug=1` で fps 55 以上 |

## 画面

画面の作りは変えない（LLM-GUI-0001）。爆風の描き方は大きさと残る時間だけが変わる。

## 範囲に入れないもの

- うまさの違うボットで自動で何度も遊ばせて点の幅を測ること（PO の決定：難しさと点の開き方は実機で遊んだ感じで決める）
- 難易度を選べること（LLM-PBI-0017）
- 新しい敵（LLM-PBI-0009）

## メモ

- 2026-11-13 の PO の決定（スプリント 10 のプランニングのリファインメント）：
  - 17:11:26：長さは「守り切ったとき 2分半〜3分半（テストでプレイした感じから、今より少し長い程度がちょうどよいと感じたため）」→ インセプションデッキの「5 分前後」を「3 分前後」に直す
  - 17:12:33 の質問の答え：「ボットを使わず実機で」
  - 「ウェーブを増やし後半ほど難しく（推奨）」、17:13:39「ウェーブ数は5にしてください。」
  - 17:14:32：多弾頭の順番は「乱数にする（推奨）」
  - 17:18:29：「調整に爆発の調整に入れます。今の爆発の大きさを1.5倍にします。爆発が最大になってから1秒爆発を残します」
- 2026-11-13 の PO の指定（実機確認 TC-0011-06 の PC の結果、17:53:27）：「簡単すぎたので、敵の攻撃を1.5倍に増やしてください。爆風の時間を1秒から0.5秒に変更してください。」→ 17:55 ごろ「A 数と密度を 1.5 倍（推奨）」（敵の数 8・12・15・18・21 → 12・18・23・27・32 発、多弾頭 0・3・4・5・6 → 0・5・6・8・9、間隔 2.0〜1.6 秒 → 1.33〜1.07 秒。長さの目安は約 2 分 54 秒のまま）→ v1.1。TASK-0040（手戻り）
- 開発者の決め：
  - 敵の数・速さ・間隔の値はウェーブごとの表にして config に置き、TASK の中で TC-0011-03 に入るよう決める（目安：敵 6・9・12・15・18 発、間隔 2.0 秒 → 1.6 秒、速さは 1.0 倍 → 1.5 倍）
  - 爆風は易しくする方向、後半の速さと間隔は難しくする方向。釣り合いは TC-0011-06 で PO が確かめ、合わなければ値だけ直す
  - 多弾頭の順番の乱数は、今の敵の乱数の並びとは別に、ウェーブの始めに種から決める（WAVE 1 の乱数の並びは変えない）
- 大きさ：S（1 TASK。ボットを作らないので M から下げた）
