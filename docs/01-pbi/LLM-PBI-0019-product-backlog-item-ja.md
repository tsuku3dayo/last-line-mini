# LLM-PBI-0019 PC でもマウスのクリックで、近い発射台から撃てる

## ストーリー

ライトユーザーとして、PC でも Z・X・C のボタンを覚えずに、マウスのクリックだけで狙った所へ撃ちたい。それは、スマートフォンと同じくらい簡単に遊べるから。

## 受け入れ条件

| 確認 ID | 条件 |
| :--- | :--- |
| LLM-TC-0019-01 | PC で、ゲーム画面を左クリックした瞬間に、クリックした所へ、横の距離がいちばん近い残弾のある基地から撃つ（基地の選び方・弾切れ・寄せ方は iPhone のタッチと同じ。LLM-GUI-0002 §2） |
| LLM-TC-0019-02 | ゲーム画面の外（黒いところ）や、右クリック・真ん中のクリックでは撃たない |
| LLM-TC-0019-03 | 方向キー・Z・X・C では、照準も動かず撃ちもしない（キーボードの操作はなくした）。マウスを動かすと照準が付いてくるのは今までどおり |
| LLM-TC-0019-04 | 画面を進めるクリック（タイトル・終わり・TOP10）では撃たない |
| LLM-TC-0019-05 | PC の Chrome のプレビューで、マウスのクリックだけで 1 プレイ遊べる。iPhone 11 のタッチは今までどおり（右下の番号が最後のコードの PR のマージと同じ） |

## 画面

LLM-GUI-0001 §3（操作。v1.7）。iPhone は LLM-GUI-0002 のまま。

## 範囲に入れないもの

- キーボードで照準を動かす・撃つ操作（PO の決定でなくす）
- ゲームパッド（LLM-PBI-0015、あとで決める）

## メモ

- 2026-11-09 のスプリント 06 のレビューで PO が依頼：「PC版：発射をZXCボタンから、マウスクリックで、近い発射台から発射する。（ライトユーザー向けに、スマホと同じく操作を簡単にする）」
- 2026-11-09 の PO の決定（スプリント 07 のプランニングのリファインメント）：**キーボードの操作（方向キーで照準・Z・X・C で発射）はなくす**
- 仕様書 §3.2（慣性の方向キー・基地ごとの 3 つの発射ボタン）とは違う操作になる。iPhone（LLM-PBI-0002 の案 C）と同じく、仕様書は書き換えず、この PBI と GUI に記録する
- スプリント 01 の PO の決定「マウスのクリックでは撃たない」（LLM-GUI-0001 §3）を変える
- キーボードは、画面を進める（TAP OR PRESS ANY KEY）・名前の入力・`?debug=1` の G キーにだけ使う
- 大きさ：S（1 TASK）
