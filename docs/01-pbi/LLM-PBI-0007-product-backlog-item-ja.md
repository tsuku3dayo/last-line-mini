# LLM-PBI-0007 ランクインしたら 3 文字の名前を入れ、自分の行が点滅する

## ストーリー

遊ぶ人として、TOP10 に入ったら名前（3 文字）を残し、ランキングで自分の行が光るのを見たい。それは、健闘が祝われてもう 1 回遊びたくなるから。

## 受け入れ条件

| 確認 ID | 条件 |
| :--- | :--- |
| LLM-TC-0007-01 | ランクインしたら、終わりの画面で触るか押すと名前の入力の画面（`NEW RECORD`・順位・点・入力欄・`OK`）になり、そのまま入力欄に打てる。ランクインしなかったら、今までどおり TOP10 の画面へ |
| LLM-TC-0007-02 | 使える文字は A〜Z・0〜9・`.` で 3 文字まで。小文字は大文字になり、ほかの文字は入らない |
| LLM-TC-0007-03 | Enter（iPhone はキーボードの確定）か `OK` で確定すると、名前つきで TOP10 に入り、TOP10 の画面になる。空のまま確定すると名前は `...` |
| LLM-TC-0007-04 | TOP10 の画面で、今回の行が 0.5 秒ごとに点滅する |
| LLM-TC-0007-05 | 名前を打っているあいだ、キーでゲームが始まったり、画面が切り替わったりしない |
| LLM-TC-0007-06 | PC の Chrome と iPhone 11 のプレビューで、ランクインして名前を入れ、TOP10 で自分の行が点滅する。iPhone ではキーボードが出て、入力欄と `OK` が隠れず、画面が勝手に拡大されない |

## 画面

LLM-GUI-0003 §3（名前の入力）・§2（TOP10 の点滅）。

## 範囲に入れないもの

- 方向キーで文字を選ぶ入れ方（仕様書 §5.1）は作らない（PO の決定）

## メモ

- 2026-11-09 の PO の決定（スプリント 06 のプランニングのリファインメント）：
  - iPhone での名前の入れ方（7a-5）：**iPhone のキーボード（入力欄）**
  - PC の入れ方：**PC も同じ入力欄にキーボードで打つ**（方向キーで選ぶ形は作らない）
- iPhone のキーボードは、触った操作の中で入力欄に入らないと出ない。終わりの画面を触ったときに入力欄に入れる（出なければ入力欄を触れば出る）。
- 大きさ：M（2 TASK）
