# LLM-PBI-0001 PC で、照準と 3 つの基地で落ちてくるミサイルを迎え撃てる

## ストーリー

遊ぶ人として、PC で照準を動かし、3 つの基地から迎撃ミサイルを撃って、落ちてくるミサイルを爆風で落としたい。それは、このゲームのいちばんの手応えだから。

## 受け入れ条件

| 確認 ID | 条件 |
| :--- | :--- |
| LLM-TC-0001-01 | 方向キーを押し続けると照準がだんだん速くなり（最高速まで）、離すとなめらかに遅くなって止まる。照準はゲーム画面の外に出ない |
| LLM-TC-0001-02 | マウスを動かすと、照準がマウスの位置にすぐ動く |
| LLM-TC-0001-03 | 発射キー（左・中・右の基地に 1 つずつ）を押すと、その基地から照準の位置へ迎撃ミサイルが直線で飛び、着いた所で爆風になる。着く場所には目印が残る |
| LLM-TC-0001-04 | 中央の基地のミサイルは、左右の基地のミサイルより速い（同じ距離なら早く着く） |
| LLM-TC-0001-05 | 各基地は 10 発ずつ持ち、撃つと 1 減る。残りの数が基地の下に出る。0 の基地のキーを押しても何も起きない |
| LLM-TC-0001-06 | 爆風は決まった半径まで広がってから縮んで消える。爆風の中に入った敵のミサイルは消える |
| LLM-TC-0001-07 | 敵のミサイルが画面の上端から、都市か基地のどれかに向かって直線で落ち、通った跡（航跡）が線で残る。地面に着くと消える（被害は LLM-PBI-0003） |
| LLM-TC-0001-08 | PC の Chrome で、プレビューの URL を開くと遊べる（画面の版の表示が main の版と同じ） |

## 画面

LLM-GUI-0001（プレイ画面）

## 範囲に入れないもの（あとの PBI）

- 誘爆、都市・基地の被弾 → LLM-PBI-0003
- ウェーブ・終わりの判定 → LLM-PBI-0004（このスプリントでは、敵が一定の間隔で落ち続ける）
- 点数・HUD の数字 → LLM-PBI-0005（HUD の場所だけ描く）
- タイトル画面 → LLM-PBI-0006（このスプリントでは、開くとすぐプレイが始まる）
- タッチ操作 → LLM-PBI-0002
