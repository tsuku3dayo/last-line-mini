# LLM-PBI-0003 誘爆が起き、都市と基地がやられる

## ストーリー

遊ぶ人として、1 発の迎撃で連鎖的にまとめて落としたい。また、守れなかったら都市や基地が壊れてほしい。それは、狙い方に戦略が生まれ、守る緊張感が出るから。

## 受け入れ条件

| 確認 ID | 条件 |
| :--- | :--- |
| LLM-TC-0003-01 | 敵のミサイルが爆風で壊れると、その弾頭の場所に、迎撃と同じ大きさ・同じ時間の爆風（誘爆）が出る。誘爆の爆風に入った敵も壊れ、さらに誘爆が続く |
| LLM-TC-0003-02 | 敵のミサイルが都市に落ちると、その都市は壊れ、がれきの見た目になる。復活しない |
| LLM-TC-0003-03 | 敵のミサイルが基地に落ちると、その基地は壊れ、残弾が 0 になる（欠けた台の見た目、残弾の数字は暗い `0`）。PC のキーでも iPhone のタッチでもその基地からは撃てない（タッチは残りの基地から撃つ） |
| LLM-TC-0003-04 | 壊れた都市・基地にも敵は落ちてくる。落ちても、閃光が出るだけで何も変わらない |
| LLM-TC-0003-05 | PC の Chrome と iPhone 11 のプレビューで、誘爆と、都市・基地が壊れるのが見られる（右下の番号がマージのコミットと同じ） |

## 画面

LLM-GUI-0001 §4（壊れた都市・基地の見た目を足す）。iPhone も同じ（LLM-GUI-0002）。

## 範囲に入れないもの（あとの PBI）

- 都市が全部壊れたら終わり（GAME OVER）→ LLM-PBI-0004
- 撃破の点・ボーナス → LLM-PBI-0005
- 敵の狙いを、残っている都市・基地に絞る → 決めない（難しさの調整 LLM-PBI-0011 で見直す）

## メモ

- 2026-11-04 の PO の決定（スプリント 02 のプランニング）：
  - 7a-3：敵が基地に当たると、その基地は壊れ、残弾が 0 になって撃てなくなる（復活しない）
  - 誘爆の爆風は、迎撃の爆風と同じ大きさ・同じ時間（半径 24、広がる 0.4 秒・保つ 0.2 秒・縮む 0.5 秒）
- 作りの案（スプリント 03 のプランニング）：
  - 誘爆の爆風は、出た次のステップから効く（1 ステップの中で連鎖が止まらなくなるのを防ぐ）
  - 「都市に落ちた」は、落ちた所が都市の幅（中心から ±12）の中。「基地に落ちた」は、基地の台の幅（中心から ±14）の中
  - 狙いは今のまま、壊れた都市・基地も狙う（狙いを変えると難しさが変わるため）
  - 地面に落ちたときは今のまま閃光だけで、爆風は出さない（出すと、隣の都市を巻き込むかという決めごとが増えるため）
