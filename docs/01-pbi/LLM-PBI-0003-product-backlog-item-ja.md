# LLM-PBI-0003 誘爆が起き、都市と基地がやられる

状態：未整理（リファインメントで、受け入れ条件・確認 ID・画面を足す）

## ストーリー

遊ぶ人として、1 発の迎撃で連鎖的にまとめて落としたい。また、守れなかったら都市や基地が壊れてほしい。それは、狙い方に戦略が生まれ、守る緊張感が出るから。

## メモ（仕様書から・決めること）

- 敵のミサイルが爆風で壊れたら、その場所に 2 つ目の爆風が出る（誘爆）
- 敵が都市に当たると、その都市は 1 発で壊れ、復活しない
- 決めること：敵が基地に当たったときの扱い（案：その基地は壊れ、残弾が 0 になる）（7a-3）
