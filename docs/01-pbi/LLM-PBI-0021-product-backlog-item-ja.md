# LLM-PBI-0021 空の敵が落とす弾の位置と速さが毎回変わる

状態：未整理（次のスプリントのリファインメントで、受け入れ条件・確認 ID を足す。並び順と PG-0002 の範囲に入れるかも確かめる）
依頼：2026-11-19 15:11 ごろ（スプリント 13 のレビューで PO が提案。15:13:48 前に PBI にすると決めた）

## ストーリー

遊ぶ人として、爆撃機と衛星が落とす弾の位置と速さが毎回違ってほしい。なぜなら、今はいつも同じ所・同じ速さで落ちるので、何度も遊ぶと読めてしまうから。

## メモ（決めること）

- 今の作り（LLM-PBI-0009）：爆撃機は道のりの 3 分の 1 と 3 分の 2 で落とす。衛星は 2.5 秒ごと。弾の速さは、そのウェーブの速さの範囲の真ん中
- 乱数にするもの：爆撃機の落とす位置（道のりのどこか）、衛星の間隔、弾の速さ（ウェーブの速さの範囲の中）。狙い（真下にいちばん近い都市・基地）も変えるか
- 乱数は空の敵の計画の並び（地上の敵と別の並び）から取り、地上の敵の出方は変えない（開発者の見込み）
- 大きさ：S の見込み
