# LLM-PBI-0021 空の敵が落とす弾の位置と速さが毎回変わる

依頼：2026-11-19 15:11 ごろ（スプリント 13 のレビューで PO が提案。15:13:48 前に PBI にすると決めた）

## ストーリー

遊ぶ人として、爆撃機と衛星が落とす弾の位置と速さが毎回違ってほしい。なぜなら、いつも同じ所・同じ速さで落ちると、何度も遊ぶと読めてしまうから。

## 受け入れ条件

| 確認 ID | 条件 |
| :--- | :--- |
| LLM-TC-0021-01 | 爆撃機は、横切る道のりの 15〜85% のどこか 2 か所（乱数）で落とす。2 か所は道のりの 20% 以上あける。出るたびに位置が変わる |
| LLM-TC-0021-02 | 衛星は、1 発ごとに 1.5〜3.5 秒の乱数の間隔で 3 発落とす。画面の中にいるうちに 3 発を落とし終える（間隔の合計が長すぎるときは縮める） |
| LLM-TC-0021-03 | 落とす弾の速さは、そのウェーブの地上の敵と同じ速さの範囲の中の乱数（1 発ごとに変わる） |
| LLM-TC-0021-04 | 狙いは今までどおり、落とした所の真下にいちばん近い都市・基地。乱数は空の敵の計画の並び（地上の敵と別の並び）から取り、同じ種なら同じ展開。地上の敵（多弾頭を含む）の出方は変わらない |
| LLM-TC-0021-05 | PC の Chrome と iPhone 11 のプレビューで、遊ぶたびに爆撃機・衛星の落とす所と速さが違い、落とせる。iPhone 11 の `?debug=1` で fps 55 以上 |

## 画面

変わらない（LLM-GUI-0001 v1.9 のまま）。

## 範囲に入れないもの

- 狙う都市・基地を乱数にすること（PO の決定：真下のまま）
- 空の敵の数・高さ・速さ（LLM-PBI-0009 のまま）

## メモ

- 2026-11-19 の PO の決定（スプリント 15 のリファインメント）：決めること 1〜6 を表の案のとおり（16:23:12 前）
- 開発者の決め：落とす時（爆撃機は道のりの割合、衛星は出てからのステップ）と、1 発ごとの速さは、ウェーブの始めに空の敵の計画（`aircraftPlan`）を作るときに一緒に決めて持たせる。値の範囲は config に置く
- 大きさ：S（1 TASK）
- 新しいブラウザの仕組みは使わない（案 25 の点検の対象外）
