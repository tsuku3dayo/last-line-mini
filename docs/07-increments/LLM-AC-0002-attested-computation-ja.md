## 3. 確認できなかったこと・気づいたこと

- **Safari に前の版が残っていた**：1 回目の確認では、Safari の右下が `556a0c7`（1 つ前のマージ）のままで、fps が出なかった。ホーム画面のアプリは新しい版になっていた。→ なぜ：新しい版を勝手に切り替えない作り（`registerType: 'prompt'`）で、ホーム画面のアプリと Safari はしまう場所が別。→ どうしたか：Safari のタブをすべて閉じて開き直してもらい、新しい版で確かめた。切り替えの「更新」ボタンは LLM-PBI-0012。実機確認の案内では、最初に右下の番号を確かめてもらう。
- **CI の E2E の 1 回目が落ちた（PR #16）**：Playwright のコンテナの中では git の履歴がなく、コミットの番号が取れなかった → ワークフローから `APP_COMMIT` を渡す形にした。
- Android・iPad・横向き：範囲の外（LLM-PBI-0002「範囲に入れないもの」）。
