# LLM-GUI-0001 プレイ画面（PC）

LLM-PBI-0001 の分に、LLM-PBI-0003（誘爆・壊れた都市と基地の見た目、§4）と LLM-PBI-0004（ウェーブと終わりの表示、§5）、LLM-PBI-0005（終わりのボーナスの内訳・照準の始めの位置、§5）、LLM-PBI-0006（HUD の TOP・終わりのあと、§1・§5。v1.6）を足した。iPhone のタッチの分は LLM-GUI-0002、タイトル・TOP10・名前の入力の画面は LLM-GUI-0003。

## 1. 配置（論理の大きさ 480 × 640、縦長）

```
 0 ┌────────────────────────────────────────┐
   │ 1P 000000                  TOP 012345  │ ← HUD（y = 8〜24）。TOP は TOP10 の 1 位の点（v1.6）
   │                                        │
   │        ＼ 敵の航跡（赤橙）              │
   │          ＼                            │
   │            ●                 ＋ ← 照準  │
   │                         ◯ ← 爆風        │
   │                       ／               │
   │                     ／ 迎撃の軌跡（緑） │
   │                   ／                   │
560│   ▲    ■  ■  ■    ▲    ■  ■  ■    ▲    │ ← 基地 A・都市 1〜3・基地 B・都市 4〜6・基地 C
   │▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁│ ← 地面（ゆるい起伏、y ≒ 580〜600）
   │   10                10                10│ ← 残弾（数字。基地の真下）
640└────────────────────────────────────────┘
```

| もの | 位置（論理座標・中心の x） |
| :--- | :--- |
| 基地 A・B・C | x = 40・240・440 |
| 都市 1〜3 | x = 100・140・180 |
| 都市 4〜6 | x = 300・340・380 |

- PC では、ブラウザの窓の中に縦長のゲーム画面を、上下いっぱいの大きさで真ん中に置く。左右は黒。
- 画面の右下の隅に、小さく版（例：`v0.1.0`）を出す。プレビューでは `v0.1.0 β aefcdbd` のように、マージのコミットの短い番号（英数字 7 桁）も出す（どのマージまで入った版かを PO が見分けるため。スプリント 01 のレトロスペクティブの案 1）。本番には付けない。

## 2. 色（独自の配色）

| もの | 色 | 備考 |
| :--- | :--- | :--- |
| 背景（夜空） | `#05070f` | ほぼ黒の紺 |
| 地面 | `#2b3b2f` の塗り、`#4f6b55` の縁 | 暗い緑灰。原作の黄色は使わない |
| 都市 | `#ffb347`（窓の灯り）と `#6b4a2a`（建物） | 暖色の灯り |
| 基地 | `#8fd3ff` | 水色の台 |
| 迎撃の軌跡・着く場所の目印 | `#6cff8a` | 緑 |
| 敵の航跡・弾頭 | `#ff5a3c` の線、`#ffffff` の先端 | |
| 爆風 | `#ffe066` → `#ff9f1c` → `#ff5a3c` と 1 ステップごとに変わる輪 | 塗りつぶしの白い円は使わない |
| 照準 | `#ffffff` の「＋」 | |
| HUD・数字 | `#e0e0e0`（1P）、`#ffb347`（TOP） | 自前の 5 × 7 ドットの文字 |

## 3. 操作（PC）

| 操作 | キー・マウス |
| :--- | :--- |
| 照準を動かす（慣性あり） | 方向キー（← ↑ → ↓） |
| 照準を動かす（すぐ） | マウスを動かす |
| 基地 A から撃つ | **Z** |
| 基地 B（中央）から撃つ | **X** |
| 基地 C から撃つ | **C** |

- 右手で方向キーかマウス、左手で Z・X・C を押す形にした（3 つの発射ボタンが左右の手で取り合いにならない）。
- マウスのクリックでは撃たない（仕様書の「3 拠点独立発射ボタン」を守るため）。

## 4. 状態とメッセージ

| 状態 | 表示 |
| :--- | :--- |
| 基地の残弾が 0 | 残弾の数字を `0` にし、暗い色（`#555555`）にする |
| 敵が地面に着いた | 小さな閃光を 0.2 秒 |
| 誘爆（LLM-PBI-0003） | 迎撃の爆風と同じ輪（§2 の爆風の色）。敵が壊れた場所に出る |
| 都市が壊れた（LLM-PBI-0003） | 建物と灯りを消し、暗い茶色 `#3a2a1a` の低いがれき（幅 20・高さ 4 ほど）を地面の上に描く |
| 基地が壊れた（LLM-PBI-0003） | 台を灰色 `#555555` にし、上の段を欠いた形にする。残弾の数字は「残弾が 0」と同じ暗い `0` |

## 5. ウェーブと終わりの表示（LLM-PBI-0004）

すべて自前の 5 × 7 ドットの文字で、ゲーム画面の中央（x = 240）にそろえて描く。原作の画面の見た目（八角形の画面など）は使わない。

```
        ┌──────────────── 480 ────────────────┐
y≒280   │               WAVE 2                 │ ← ウェーブのあいだ（約 3 秒）。文字の大きさ 4 倍、#e0e0e0
        │                                      │
y≒280   │          DEFENSE COMPLETE            │ ← CLEAR。3 倍、#6cff8a（緑）
y≒280   │               THE END                │ ← GAME OVER。4 倍、#ff5a3c（赤橙）
y≒330   │       MISSILES 12 X 5     60         │ ← 終わりのボーナスの内訳（LLM-PBI-0005、v1.5）。2 倍、#e0e0e0
y≒354   │       CITIES    4 X 100  400         │ ← 同上（GAME OVER のときは CITIES 0 X 100 0）
y≒400   │        TAP OR PRESS ANY KEY          │ ← 終わりの約 1 秒あとから。2 倍、#e0e0e0 で 0.5 秒ごとに点滅（v1.5 で y 340 → 400）
        └──────────────────────────────────────┘
```

- 終わりのボーナスの内訳（LLM-PBI-0005）：終わった瞬間から出す。同じ瞬間に、残弾 × 5 と残った都市 × 100 を足した点を HUD の `1P` に出す（数え上げの動きは付けない）。
- 照準の始めの位置（LLM-PBI-0005、v1.5）：(240, 420)（「WAVE 1」の文字 y = 280〜308 と重ならないように。v1.4 までは (240, 300)）。WAVE 2 からは、プレイヤーが置いた所のまま。
- HUD の `TOP` は、TOP10 の 1 位の点（記録がなければ `000000`。LLM-PBI-0006、v1.6。v1.5 までは `000000` のまま）。

| 場面 | 表示 |
| :--- | :--- |
| 始め・ウェーブのあいだ | 「WAVE n」を約 3 秒（n は次のウェーブ） |
| CLEAR | 「DEFENSE COMPLETE」。画面の都市・基地はそのまま見える |
| GAME OVER | ゲームがその場で止まり（敵・爆風も止まる）、その上に「THE END」 |
| 終わりの約 1 秒あと | 「TAP OR PRESS ANY KEY」を点滅。触るかキーを押すと、ランクインしたら名前の入力、しなければ TOP10 の画面へ（LLM-GUI-0003。v1.6。v1.5 までは WAVE 1 から） |
| CLEAR・GAME OVER のあいだ | 照準の「＋」を描かない（中央の文字と重ならないように。v1.4、実機確認で PO が決めた）。WAVE 1 になると、また描く |

## 6. PO に決めてほしいこと（LLM-PBI-0001 のとき）

- 配色（§2）でよいか
- 発射キー Z・X・C（§3）でよいか（ほかの案：A・S・D）
- マウスのクリックで撃たない、でよいか
