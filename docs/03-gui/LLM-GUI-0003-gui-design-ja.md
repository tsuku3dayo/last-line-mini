# LLM-GUI-0003 タイトル・TOP10・名前の入力の画面（PC・iPhone）

LLM-PBI-0006・0007 の画面。配置の大きさ（論理 480 × 640）・色・文字（自前の 5 × 7 ドット）・iPhone での置き方は LLM-GUI-0001・0002 のまま。文字はすべて中央（x = 240）にそろえる。

## 0. 画面の流れ

```
 開く ─▶ タイトル ─触る／押す─▶ WAVE 1 … プレイ … 終わり（THE END／DEFENSE COMPLETE・内訳）
            ▲                                              │ 約 1 秒後に触る／押す
            │                                              ▼
            └──触る／押す── TOP10 ◀── 確定 ──［名前の入力］（ランクインしたときだけ。LLM-PBI-0007）
                          （今回の行が点滅）     ランクインしなければ、終わりから TOP10 へ
```

- 触る／押すは、今の「TAP OR PRESS ANY KEY」と同じ（画面のどこでも・どのキーでも）。どの画面も、出てから約 1 秒は受け付けない（前の画面の操作で飛ばないように）。
- タイトルと TOP10 の画面では、プレイの絵（敵・基地・都市・地面）は描かない。照準も描かない。

## 1. タイトル画面（LLM-PBI-0006）

```
        ┌──────────────── 480 ────────────────┐
y≒ 72   │           LAST LINE MINI             │ ← 4 倍、#6cff8a（緑）
y≒136   │               TOP 10                 │ ← 2 倍、#ffb347
y≒176   │          1  AAA  012345              │ ← 2 倍、#e0e0e0。行の間は 28（y 176〜428 の 10 行）
y≒204   │          2  B.C  009870              │
        │          …                           │
y≒428   │         10  ---  000000              │ ← 記録のない行は名前 `---`・点 `000000`、#555555（暗い）
y≒520   │        TAP OR PRESS ANY KEY          │ ← 2 倍、#e0e0e0、0.5 秒ごとに点滅
        └──────────────────────────────────────┘
```

- 1 行は `順位（右寄せ 2 桁）  名前（3 文字）  点（6 桁）`。等幅なので列がそろう。
- HUD（`1P`・`TOP`）と右下の版は、どの画面でも出す。`TOP` は TOP10 の 1 位の点（LLM-GUI-0001 §1 v1.6）。

## 2. TOP10 の画面（LLM-PBI-0006・0007）

```
y≒ 72   │               TOP 10                 │ ← 4 倍、#ffb347
y≒176   │          1  AAA  012345              │ ← タイトルと同じ 10 行
        │          …                           │
y≒232   │          3  YOU  001735              │ ← 今回の行：#6cff8a で 0.5 秒ごとに点滅（LLM-PBI-0007）
        │          …                           │
y≒464   │         YOUR SCORE 001735            │ ← 2 倍、#e0e0e0。ランクインしなくても出す
y≒520   │        TAP OR PRESS ANY KEY          │ ← 点滅。触る／押すとタイトルへ
```

- LLM-PBI-0007 ができるまでは、ランクインした行の名前は `...`、点滅もしない。

## 3. 名前の入力の画面（LLM-PBI-0007）

キーボードが下から出ても隠れないよう、上半分に置く。

```
y≒ 64   │             NEW RECORD               │ ← 4 倍、#6cff8a
y≒120   │        RANK 3   SCORE 001735         │ ← 2 倍、#e0e0e0
y≒168   │           ENTER YOUR NAME            │ ← 2 倍、#ffb347
y≒200   │            ┌───────────┐             │
        │            │   A B _   │             │ ← 入力欄（HTML の入力欄をゲーム画面の上に重ねる）。幅 144・高さ 48（論理）
y≒248   │            └───────────┘             │    文字は大文字の等幅、枠 #6cff8a、背景 #05070f
y≒264   │            [    OK    ]              │ ← ボタン。幅 144・高さ 58（論理）。一番小さい iPhone SE 第 3 世代（倍率 0.78）で約 45 ポイント（TEAM 5.2 の 44 以上）
        └──────────────────────────────────────┘
```

| 操作 | 起きること |
| :--- | :--- |
| 画面に入ったとき | 入力欄に入る（PC はそのまま打てる。iPhone は終わりの画面を触った操作の中で入力欄に入れ、キーボードを出す。出なければ入力欄を触る） |
| 文字を打つ | A〜Z・0〜9・`.` だけ入る。小文字は大文字にする。3 文字まで |
| Enter（iPhone はキーボードの確定）・`OK` を触る／クリック | 確定。空なら名前は `...`。TOP10 の画面へ |
| 入力欄の外を触る | 何も起きない（キーボードが閉じるだけ。確定はしない） |

- iPhone の Safari は、入力欄の文字が 16 px より小さいと画面を勝手に拡大する → 入力欄の文字は 16 px 以上にする。
- 入力欄の中のキーは、ゲームの操作（やり直し・G キーなど）に使わない（TEAM 5.3）。
- タッチのガード（LLM-GUI-0002 §3：ゲーム画面の `touchstart` の既定の動きを止める）は、入力欄と `OK` には効かせない（効くと入力欄に入れない）。
- 入力欄は自動の大文字（`autocapitalize`）・自動の直し（`autocorrect`）・候補（`autocomplete`）を切る。
