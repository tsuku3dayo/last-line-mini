# LLM-GUI-0003 タイトル・TOP10・名前の入力の画面（PC・iPhone）

LLM-PBI-0006・0007・0020 の画面と、LLM-PBI-0012 の更新の帯・起動の復旧の画面（§5・§6。v1.2）。配置の大きさ（論理 480 × 640）・色・文字（自前の 5 × 7 ドット）・iPhone での置き方は LLM-GUI-0001・0002 のまま。文字はすべて中央（x = 240）にそろえる。ただし **名前だけはブラウザの文字（ゴシック）** で描く（自前の文字は英数字だけのため。LLM-PBI-0020。v1.1）。

## 0. 画面の流れ

```
 開く ─▶ タイトル ─触る／押す─▶ WAVE 1 … プレイ … 終わり（THE END／DEFENSE COMPLETE・内訳）
            ▲                                              │ 約 1 秒後に触る／押す
            │                                              ▼
            └──触る／押す── TOP10 ◀── 確定 ──［名前の入力］（ランクインしたときだけ。LLM-PBI-0007）
                          （今回の行が点滅）     ランクインしなければ、終わりから TOP10 へ
```

- 触る／押すは、今の「TAP OR PRESS ANY KEY」と同じ（画面のどこでも・どのキーでも）。どの画面も、出てから約 1 秒は受け付けない（前の画面の操作で飛ばないように）。
- タイトルと TOP10 の画面では、プレイの絵（敵・基地・都市・地面）は描かない。照準も描かない。

## 1. タイトル画面（LLM-PBI-0006）

```
        ┌──────────────── 480 ────────────────┐
y≒ 72   │           LAST LINE MINI             │ ← 4 倍、#6cff8a（緑）
y≒136   │               TOP 10                 │ ← 2 倍、#ffb347
y≒176   │      1  やまだたろう      012345     │ ← 2 倍、#e0e0e0。行の間は 28（y 176〜428 の 10 行）
y≒204   │      2  AAA               009870     │
        │      …                               │
y≒428   │     10  ---               000000     │ ← 記録のない行は名前 `---`・点 `000000`、#555555（暗い）
y≒520   │        TAP OR PRESS ANY KEY          │ ← 2 倍、#e0e0e0、0.5 秒ごとに点滅
        └──────────────────────────────────────┘
```

- 1 行は `順位（右寄せ 2 桁）  名前（8 文字の枠）  点（6 桁）`。列の位置は決めておく（v1.1）：順位は x 72〜96（右寄せ）、名前は x 120 から左寄せ（枠は x 120〜312、幅 192）、点は x 336〜408。1 行の幅は 336 で、画面の中央にそろう。
- 名前はブラウザの文字（ゴシック・太字）、大きさ 20（論理）。行の色・暗さ・点滅は順位と点と同じ。全角 8 文字で幅 160 なので枠に収まる。`---` と `...` も同じ文字で描く。
- HUD（`1P`・`TOP`）と右下の版は、どの画面でも出す。`TOP` は TOP10 の 1 位の点（LLM-GUI-0001 §1 v1.6）。

## 2. TOP10 の画面（LLM-PBI-0006・0007）

```
y≒ 72   │               TOP 10                 │ ← 4 倍、#ffb347
y≒176   │          1  AAA  012345              │ ← タイトルと同じ 10 行
        │          …                           │
y≒232   │      3  ゆうと            001735     │ ← 今回の行：#6cff8a で 0.5 秒ごとに点滅（名前も。LLM-PBI-0007・0020）
        │          …                           │
y≒464   │         YOUR SCORE 001735            │ ← 2 倍、#e0e0e0。ランクインしなくても出す
y≒520   │        TAP OR PRESS ANY KEY          │ ← 点滅。触る／押すとタイトルへ
```

- LLM-PBI-0007 ができるまでは、ランクインした行の名前は `...`、点滅もしない。

## 3. 名前の入力の画面（LLM-PBI-0007）

キーボードが下から出ても隠れないよう、上半分に置く。

```
y≒ 64   │             NEW RECORD               │ ← 4 倍、#6cff8a
y≒120   │        RANK 3   SCORE 001735         │ ← 2 倍、#e0e0e0
y≒168   │           ENTER YOUR NAME            │ ← 2 倍、#ffb347
y≒200   │      ┌───────────────────────┐       │
        │      │  やまだたろう_        │       │ ← 入力欄（HTML の入力欄をゲーム画面の上に重ねる）。幅 288（x 96〜384）・高さ 48（論理。v1.1 で 144 から広げた）
y≒248   │      └───────────────────────┘       │    文字はブラウザの文字（ゴシック）・大きさ 24（論理。16 px より小さくしない）、枠 #6cff8a、背景 #05070f
y≒264   │            [    OK    ]              │ ← ボタン。幅 144・高さ 58（論理）。一番小さい iPhone SE 第 3 世代（倍率 0.78）で約 45 ポイント（TEAM 5.2 の 44 以上）
        └──────────────────────────────────────┘
```

| 操作 | 起きること |
| :--- | :--- |
| 画面に入ったとき | 入力欄に入る（PC はそのまま打てる。iPhone は終わりの画面を触った操作の中で入力欄に入れ、キーボードを出す。出なければ入力欄を触る） |
| 文字を打つ | ひらがな・カタカナ・漢字・英字（大文字も小文字もそのまま）・数字・記号が入る。絵文字・空白・そのほかは消える。見た目の 1 文字を 1 文字として 8 文字まで（v1.1。LLM-PBI-0020） |
| 日本語入力の変換中（確定する前） | 打った文字はそのまま（消したり切ったりしない）。Enter は変換の確定だけで、名前は確定しない。変換を確定したところで、使えない文字を消し 8 文字に切る |
| Enter（iPhone はキーボードの確定）・`OK` を触る／クリック | 確定（変換中の Enter は除く）。空なら名前は `...`。TOP10 の画面へ |
| 入力欄の外を触る | 何も起きない（キーボードが閉じるだけ。確定はしない） |

- iPhone の Safari は、入力欄の文字が 16 px より小さいと画面を勝手に拡大する → 入力欄の文字は 16 px 以上にする。
- 入力欄の中のキーは、ゲームの操作（やり直し・G キーなど）に使わない（TEAM 5.3）。
- タッチのガード（LLM-GUI-0002 §3：ゲーム画面の `touchstart` の既定の動きを止める）は、入力欄と `OK` には効かせない（効くと入力欄に入れない）。
- 入力欄は自動の大文字（`autocapitalize`）・自動の直し（`autocorrect`）・候補（`autocomplete`）を切る。

## 4. 保存（画面には出ないもの）

- キー：本番 `last-line-mini-ranking`、プレビュー `last-line-mini-preview-ranking`（LLM-SA-0001 §2）
- 中身が壊れていたら、空の TOP10 として扱い、次の保存で書き直す。
- 名前の検査は新しい決まり（使える文字・8 文字まで、または `...`）。今までの英字 3 文字・`...` の記録もこの決まりに合うので、そのまま読める（v1.1）。

## 5. 更新の帯（LLM-PBI-0012。v1.2）

新しい版を見つけたときだけ、**タイトルと TOP10 の画面** で、ゲーム画面の上の端に重ねる（PO の決定、2026-11-18：「B 上の帯（日本語）」）。

```
        ┌──────────────── 480 ────────────────┐
y 0〜64 │ 新しい版があります      ［ 更新 ］   │ ← 帯：高さ 64（論理）、背景 #05070f、下の線 #6cff8a
        ├──────────────────────────────────────┤
y≒ 72   │           LAST LINE MINI             │ ← タイトルはそのまま（帯の下に見える）
        │               …                      │
```

- 帯はブラウザの文字（ゴシック）の HTML。文字は大きさ 20（論理）・#e0e0e0、左に余白 16。
- 「更新」ボタン：幅 120・高さ 60（論理。帯の上下に 2 ずつ）、枠 #6cff8a・文字 #6cff8a・太字、右に余白 8。一番小さい iPhone SE 第 3 世代（倍率 約 0.75）で約 45 ポイント（TEAM 5.2 の 44 以上。2026-11-18 11:36:08 に PO の承認で 58 → 60：58 では E2E で 43.5 ポイントだった）。
- 帯は HUD（`1P`・`TOP`）の上に重なる（タイトルと TOP10 の画面では HUD が隠れてもよい）。
- プレイ中・終わりの表示・名前の入力の画面では出さない。その間に見つけたら、次にタイトルか TOP10 に来たときに出す。

| 操作 | 起きること |
| :--- | :--- |
| 「更新」を触る／クリック | 新しい版に切り替えて読み込み直す（タイトルの画面から始まる。ランキングは残る） |
| 帯の「更新」の外（文字のところ）を触る／クリック | 何も起きない（ゲームは始まらない） |
| 帯の外を触る／押す・キーを押す | 今までどおり（タイトルなら始まる・TOP10 ならタイトルへ）。帯は次の画面では消え、またタイトルか TOP10 に来たら出る |

- タッチのガード（LLM-GUI-0002 §3）は帯に効かせない（効くとボタンが押せない）。帯の `pointerdown` はゲームの「触る／押す」に届かないよう止める。

## 6. 起動の復旧の画面（LLM-PBI-0012。v1.2）

アプリの本体が **8 秒たっても** 最初の画面を出せないときだけ、画面いっぱいに出す。アプリの CSS が読めていない前提で、見た目は HTML のインラインの style で決める（ブラウザの文字）。

```
        ┌──────────────────────────────────────┐
        │                                      │ 背景 #000000、文字 #e0e0e0
        │     起動できませんでした              │ ← 大きさ 20px・太字
        │                                      │
        │  通信の状態を確かめて、               │ ← 16px
        │  読み込み直してください。             │
        │                                      │
        │  ┌────────────────────────────┐      │
        │  │        再読み込み          │      │ ← ボタン 高さ 48px 以上・幅 260px
        │  └────────────────────────────┘      │
        │  ┌────────────────────────────┐      │
        │  │ キャッシュを消して再読み込み │      │
        │  └────────────────────────────┘      │
        │  ランキングは消えません。             │ ← 14px・#aaaaaa
        └──────────────────────────────────────┘
```

| 操作 | 起きること |
| :--- | :--- |
| 「再読み込み」 | そのまま読み込み直す |
| 「キャッシュを消して再読み込み」 | 自分のチャンネルの SW の登録と、自分の `<app-id>` のキャッシュだけを消してから読み込み直す（本番 `last-line-mini`・プレビュー `last-line-mini-preview`。もう一方のチャンネルのものは消さない）。localStorage（ランキング）は消さない |
