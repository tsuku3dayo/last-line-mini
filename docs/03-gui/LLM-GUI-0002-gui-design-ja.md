# LLM-GUI-0002 プレイ画面（iPhone のタッチ）

LLM-GUI-0001（PC）に、iPhone のタッチの分を足す。配置・色は LLM-GUI-0001 のまま変えない。

## 1. 配置（縦の画面）

```
┌──── iPhone 11（414 × 896）────┐   ┌─ iPhone SE 第 3 世代（375 × 667）─┐
│▓▓▓▓▓▓ ノッチ（安全領域）▓▓▓▓▓▓│   │                                    │
│                               │   │┌──────────────────────────────────┐│
│┌─────────────────────────────┐│   ││ 1P 000000           TOP 000000   ││
││ 1P 000000        TOP 000000 ││   ││                                  ││
││                             ││   ││   ゲーム画面 375 × 500            ││
││                             ││   ││   （倍率 0.78）                   ││
││   ゲーム画面 414 × 552       ││   ││                                  ││
││   （倍率 0.86）              ││   ││ ▲  ■ ■ ■  ▲  ■ ■ ■  ▲            ││
││                             ││   │└──────────────────────────────────┘│
││ ▲  ■ ■ ■  ▲  ■ ■ ■  ▲       ││   │                                    │
│└─────────────────────────────┘│   └────────────────────────────────────┘
│                               │
│▓▓▓▓▓ ホームバー（安全領域）▓▓▓▓│
└───────────────────────────────┘
```

- ゲーム画面は、安全領域を引いた広さに縦横の比を保って最大の大きさで、真ん中に置く（今の `computeLayout` のまま）。上下・左右のあまりは黒。
- 発射ボタン・操作空間は置かない（案 C）。そのぶんゲーム画面が大きくなる。
- 版の表示は LLM-GUI-0001 と同じく、ゲーム画面の右下の隅。

## 2. 操作（タッチ）

| 操作 | 起きること |
| :--- | :--- |
| ゲーム画面を触る（指が付いた瞬間） | 照準を触った所に移し、横の距離がいちばん近い残弾のある基地から、そこへ撃つ |
| 触ったまま指をすべらせる | 何も起きない（撃たない・照準も動かない） |
| 2 本の指で同時に触る | それぞれの場所へ 1 発ずつ（基地の選び方は 1 発ずつ順に決める） |
| ゲーム画面の外（黒いところ）を触る | 何も起きない |

**基地の選び方**

| 触った所の x（論理座標） | 選ぶ基地（残弾があれば） |
| :--- | :--- |
| 140 より左 | A（x = 40） |
| 140 〜 340 | B（x = 240）。ちょうど 140・340（同じ距離）のときも B |
| 340 より右 | C（x = 440） |

- 選んだ基地が 0 なら、次に近い基地。距離が同じなら A を先に（B が 0 で、x = 240 のとき）。
- 3 つとも 0 なら何も起きない（PC で 0 の基地のキーを押したときと同じ）。

**触れる高さ**：HUD の上や地面の下を触ったときは、PC の照準と同じ範囲（地面より上・HUD より下）に寄せた所へ撃つ（試作と同じ）。

## 3. 止めるもの（TEAM 5.2）

- 長押しの虫めがね・メニュー、文字の選択、2 回タップの拡大：ゲーム画面で `touchstart` の既定の動きを止める（`{ passive: false }`）。CSS の `touch-action: none`・`user-select: none`・`-webkit-touch-callout: none` も付ける。
- 2 本指の拡大：`gesturestart` を止める。
- スクロール・引っぱり：`body` を `position: fixed; inset: 0`、`overscroll-behavior: none`。

## 4. 状態とメッセージ

| 状態 | 表示 |
| :--- | :--- |
| 撃った | PC と同じ（迎撃の軌跡・着く場所の目印）。指で目印が隠れても、指を離せば見える |
| 3 つとも残弾 0 で触った | 何も出さない |

## 5. PO が決めたこと（2026-11-04）

- 距離が同じときは B を先に、A と C なら A（§2）
- HUD の上・地面の下を触ったときは、範囲に寄せて撃つ（§2）
- 触ったまま指をすべらせても撃たない・照準も動かない（§2）
