# LLM-TC-0012 テストケース

| 確認 ID | 確かめること | 方法 | 場所 |
| :--- | :--- | :--- | :--- |
| LLM-TC-0012-01 | 新しい版を見つけたとき、タイトル・TOP10 の画面にだけ帯が出る。プレイ中・終わり・名前の入力では出ず、そのあとタイトルか TOP10 に来たときに出る。勝手に切り替わらない | 自動（単体：画面ごとに帯を出すかの判定。E2E：`simulateUpdate` で帯を出し、プレイを始めて消え、TOP10 で出る） | `tests/unit/update.test.ts`、`e2e/update.spec.ts` |
| LLM-TC-0012-02 | 「更新」で切り替えの関数が呼ばれ読み込み直す。帯の中を触ってもゲームが始まらない（帯の外では始まる）。ボタンが iPhone SE 第 3 世代で 44 ポイント以上 | 自動（E2E：`simulateUpdate` の偽の切り替えが呼ばれた回数・画面の状態・ボタンの大きさ）＋スクリーンショット（PC 1280 × 800・iPhone SE 375 × 667 のタイトル・TOP10 で帯を目で見る） | `e2e/update.spec.ts` |
| LLM-TC-0012-03 | 登録の直後と、`visibilitychange` で見えたとき（オンライン）に `registration.update()` を呼ぶ。隠れたとき・オフラインのときは呼ばない | 自動（単体：偽の registration で呼ばれた回数） | `tests/unit/update.test.ts` |
| LLM-TC-0012-04 | 本体の読み込みを止めると 8 秒後に復旧の画面が出る。ふだんの起動では出ない。「キャッシュを消して再読み込み」は自分の `<app-id>` のキャッシュと自分の範囲の SW の登録だけを消し、localStorage のランキングは残る | 自動（E2E：`page.route` で本体を止め `page.clock` で 8 秒進める。キャッシュに本番・プレビューの両方の名前を置いて片方だけ消えること。SW の登録は偽物の 2 つで、プレビューの範囲だけ消すこと。Chromium） | `e2e/boot.spec.ts` |
| LLM-TC-0012-05 | dist に `boot.js` があり、`index.html` がアプリ本体より先に読む。本番の SW がプレビューのページを扱わない（今までの検査が通る） | 自動（dist の検査：プレビュー・本番の両方。E2E：今までの本番がプレビューを扱わない検査） | `scripts/check-dist.mjs`、`e2e/pwa.spec.ts` |
| LLM-TC-0012-06 | iPhone 11 のホーム画面のプレビューで、次の版が公開されたあと前に戻すと帯が出て、「更新」で右下の番号が新しくなり、ランキングが残る | 手動（実機） | 手順：0012 のマージのあと、ホーム画面のプレビューを開いて右下の番号を書き留め、ランキングに 1 つ記録を残す → 次のマージの公開が終わったら、アプリを前に戻す（出なければ一度ほかのアプリに切り替えて戻す） → タイトルの上に帯が出る → 「更新」 → 右下の番号が新しいマージの番号・ランキングが残る → iPhone 11 の Safari でプレビューを `?debug=1` で開き、1 プレイして fps 55 以上（完成の定義。帯は HTML で、プレイ中は出ないので描く量は変わらない見込み） |
