# LLM-PG-0004 プロダクトゴール 4（タイトル画面の BGM）

オーナーが、PC と iPhone（ホーム画面のアプリを含む）でタイトル画面を開いているあいだも、プレイ中とは別の BGM が鳴り、遊ぶ前から「都市を守る」雰囲気が伝わる状態にする。タイトルとプレイで曲が切り替わることで、始まった・戻ったが耳で分かり、「♪ 音 ON／OFF」を押したときに音が出るかもタイトルですぐ確かめられる。そろったら、本番に v1.3.0 として公開する。

- 対象の利用者：オーナー（すき間時間にスコアアタックを遊ぶ人）
- 対象の端末・公開先：LLM-PG-0001 と同じ（PC の Chrome・Edge、iPhone 11 の Safari・ホーム画面のアプリ／本番 `https://tsuku3dayo.github.io/last-line-mini/`）
- 範囲：
  1. LLM-PBI-0023（タイトル画面の BGM。2026-11-20 に PO が依頼した）
- 前提（ブラウザの決まり）：最初に画面に触るまで音は出せない。アプリを開いて最初の 1 回目は、タイトルに触ったあとから鳴る。「♪ 音 ON／OFF」が OFF のときは鳴らさない（今と同じ）
- 作らないもの：
  - 音のファイル（今の BGM と同じく、Web Audio の合成で作る）
  - 設定の画面（音の大きさを選ぶなど）、ウェーブごとのメロディ、止めた画面に WAVE と点（候補のまま。PBI にしていない）
  - LLM-PG-0001〜0003 の「作らないもの」もそのまま
- 達成をどう確かめるか：LLM-PBI-0023 が `完成` で PO に受け入れられ、v1.3.0 として本番に公開され、オーナーが iPhone 11 のホーム画面のアプリと PC で、タイトルの BGM が鳴る・プレイに入ると曲が切り替わる・タイトルに戻るとまたタイトルの曲になる・OFF で鳴らない、を確かめた
