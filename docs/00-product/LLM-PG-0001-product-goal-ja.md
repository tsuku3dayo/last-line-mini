# LLM-PG-0001 プロダクトゴール

オーナーが、PC と iPhone のブラウザ（ホーム画面のアプリを含む）で、通常弾と多弾頭ミサイルが降る『最終防衛線ミニ』の 1 面を最後まで遊び、TOP10 に名前を残せる状態にして、本番に公開する。

- 対象の利用者：オーナー（すき間時間にスコアアタックを遊ぶ人）
- 対象の端末・公開先：PC（Chrome・Edge）、iPhone 11（Safari・ホーム画面のアプリ）／GitHub Pages の本番 `https://tsuku3dayo.github.io/last-line-mini/`
- 作らないもの：
  - 原作の名前・ロゴ・画面の再現、オンラインランキング、都市の復活・ボーナス都市、2 面以降、2 人プレイ、実物のトラックボール専用の対応、Android の実機での確認（IDK 問い 4）
  - **爆撃機・衛星・スマートミサイル**（仕様書 §4.1。次のプロダクトゴールの候補：LLM-PBI-0009・0010）
- 達成をどう確かめるか：プロダクトバックログの順 1〜12 の PBI（LLM-PBI-0001〜0008・0011〜0013・0019）がすべて `完成` で PO に受け入れられ、v1.0.0 として本番に公開され、オーナーが iPhone 11 のホーム画面のアプリで 1 プレイ（タイトル → プレイ → 結果 → ネームエントリー → TOP10）を通して確かめた
