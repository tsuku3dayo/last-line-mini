# LLM-PG-0002 プロダクトゴール 2（爆撃機と衛星・音）

オーナーが、PC と iPhone（ホーム画面のアプリを含む）で、空を横切る爆撃機と衛星も降らせてくる 1 面を、撃つ・爆発する・都市がやられる音と BGM を聞きながら遊び、ミサイルを落とすか元を断つかを選んで高い点を狙える状態にして、本番に v1.1.0 として公開する。

- 対象の利用者：オーナー（すき間時間にスコアアタックを遊ぶ人）
- 対象の端末・公開先：LLM-PG-0001 と同じ（PC の Chrome・Edge、iPhone 11 の Safari・ホーム画面のアプリ／本番 `https://tsuku3dayo.github.io/last-line-mini/`）
- 範囲：LLM-PBI-0009（爆撃機と衛星）→ LLM-PBI-0014（効果音・BGM）の順
- 作らないもの：
  - 一時停止（LLM-PBI-0016。次のゴールの候補。案 B〔アプリを離れたら自動でも止まる〕は 2026-11-19 に選んだまま残す）、ランキングの書き出し・読み込み（LLM-PBI-0018）
  - スマートミサイル（2026-11-13 に PO が削除）
  - LLM-PG-0001 の「作らないもの」もそのまま
- 達成をどう確かめるか：LLM-PBI-0009・0014 が `完成` で PO に受け入れられ、v1.1.0 として本番に公開され、オーナーが iPhone 11 のホーム画面のアプリで、爆撃機・衛星が出て音が鳴る 1 プレイを通して確かめた
