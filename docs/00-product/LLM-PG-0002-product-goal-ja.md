# LLM-PG-0002 プロダクトゴール 2（一時停止）

オーナーが、PC と iPhone（ホーム画面のアプリを含む）で遊んでいる途中に、自分で止めても、電話や通知でアプリを離れても、戻って「続ける」を押すまでゲームが進まず、止めたところから続きを遊べる状態にして、本番に v1.1.0 として公開する。

- 対象の利用者：オーナー（すき間時間にスコアアタックを遊ぶ人。途中で手が離れることがある）
- 対象の端末・公開先：LLM-PG-0001 と同じ（PC の Chrome・Edge、iPhone 11 の Safari・ホーム画面のアプリ／本番 `https://tsuku3dayo.github.io/last-line-mini/`）
- 範囲：LLM-PBI-0016（一時停止）。ボタンで止める・続ける・やめてタイトルへ、アプリを離れたら自動で止まる
- 作らないもの：
  - アプリを閉じた・iPhone がアプリを終わらせたあとに、続きから遊ぶこと（ゲームの状態の保存。PO が案 C を選ばなかった）
  - 効果音・BGM（LLM-PBI-0014）、ランキングの書き出し・読み込み（LLM-PBI-0018）、爆撃機と衛星（LLM-PBI-0009）
  - LLM-PG-0001 の「作らないもの」もそのまま
- 達成をどう確かめるか：LLM-PBI-0016 が `完成` で PO に受け入れられ、v1.1.0 として本番に公開され、オーナーが iPhone 11 のホーム画面のアプリで、プレイの途中に止めて続ける・アプリを離れて戻ると止まっている、を確かめた

## 案（2026-11-19 に PO が選んだ）

| 案 | 中身 | 見込み |
| :--- | :--- | :--- |
| A | ボタンで止める・続ける・やめてタイトルへ、だけ | 1 スプリント |
| **B（選んだ）** | A に加え、アプリを離れたら自動で止まり、戻っても「続ける」を押すまで動かない（今は戻った瞬間に動き出す） | 1〜2 スプリント |
| C | B に加え、アプリを閉じても次に開いたとき続きから（ゲームの状態を保存する） | 2〜3 スプリント |
