# LLM-PG-0003 プロダクトゴール 3（一時停止）

オーナーが、PC と iPhone（ホーム画面のアプリを含む）で遊んでいる途中に、自分で止めても、電話や通知でアプリを離れても、戻って「続ける」を押すまでゲームが進まず、止めたところから続きを遊べる状態にして、本番に v1.2.0 として公開する。

- 対象の利用者：オーナー（すき間時間にスコアアタックを遊ぶ人。途中で手が離れることがある）
- 対象の端末・公開先：LLM-PG-0001 と同じ（PC の Chrome・Edge、iPhone 11 の Safari・ホーム画面のアプリ／本番 `https://tsuku3dayo.github.io/last-line-mini/`）
- 範囲：LLM-PBI-0016（一時停止。案 B：ボタンで止める・続ける・やめてタイトルへ、アプリを離れたら自動で止まる）
- 作らないもの：
  - アプリを閉じた・iPhone がアプリを終わらせたあとに、続きから遊ぶこと（ゲームの状態の保存。案 C は選ばなかった）
  - ランキングの書き出し・読み込み（LLM-PBI-0018）、設定の画面、ウェーブごとのメロディ（スプリント 14 のレビューで出た候補）
  - LLM-PG-0001・0002 の「作らないもの」もそのまま
- 達成をどう確かめるか：LLM-PBI-0016 が `完成` で PO に受け入れられ、v1.2.0 として本番に公開され、オーナーが iPhone 11 のホーム画面のアプリで、プレイの途中に止めて続ける・アプリを離れて戻ると止まっている、を確かめた
