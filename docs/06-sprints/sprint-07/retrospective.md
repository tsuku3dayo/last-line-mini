## 言葉の表

| 言葉 | 意味 |
| :--- | :--- |
| PBI | プロダクトバックログの 1 項目（作りたいもの 1 つ） |
| TASK | PBI を作るための作業 1 つ。1 TASK ＝ 1 PR |
| PR | 変更を本流に入れてよいか確かめてもらう申請 |
| CI | PR ごとに自動でテストを動かす仕組み。緑なら合格 |
| E2E | 本物のブラウザでアプリを動かして確かめる自動テスト。iPhone は「まね」で動かす |
| 手戻り | 確認やレビューのあとで足した TASK や直し |
| 待ち（B1・B3） | PO の答え・確認・マージ、CI を待っていた時間 |
| 仕掛かり | 手を付けたが、まだ完成していない作業 |
| VSM（バリューストリームマッピング） | 依頼から届くまでの段階を並べ、段階ごとの作業の時間・待ち・差し戻しを書いた図。どこで詰まっているかを見つけるために使う |
| PT・LT | PT：その段階で手を動かした時間。LT：その段階に入ってから出るまでの時間（待ちを含む） |
| %C/A | その段階の出したものが、次の段階で直しや差し戻しなしに使えた割合 |
