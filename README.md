# 最終防衛線ミニ

空から降ってくるミサイルを、3 つの基地から撃ち上げる弾の爆風で迎え撃ち、6 つの都市を守るゲームです。
5 つのウェーブを守りきると DEFENSE COMPLETE。後半ほど敵が増え、途中で分かれる多弾頭ミサイルも降ってきます。WAVE 2 からは爆撃機と衛星が空を横切ってミサイルを落とします（壊すと 100 点）。1 プレイは 3 分前後です。
点数は TOP10 に残り、ランクインしたら名前（日本語も使えます。8 文字まで）を入れられます。

このゲームはオリジナル作品です。PC と iPhone のブラウザで遊べ、iPhone ではホーム画面に置いてアプリのように使えます。

## 遊び方

タイトル画面で画面のどこかを触る（PC はクリックか、どれかのキーを押す）と始まります。

| | PC | iPhone |
| :--- | :--- | :--- |
| 狙う | マウスを動かす | — |
| 撃つ | ゲーム画面を左クリック | ゲーム画面を触る（2 本の指で 2 か所に撃てます） |

- 撃った所に向かって、横にいちばん近い、弾の残っている基地から弾が飛び、着いた所で爆風が広がります。爆風に触れたミサイルは壊れ、壊れたミサイルの爆風でも誘爆します。
- 基地の弾には限りがあります（1 つの基地に 15 発）。ウェーブが変わると補充されます。
- 爆撃機と衛星も、撃った所の爆風に巻き込むと壊れます。落とされる前に元を断つか、落ちてくるミサイルを落とすかを選べます。
- 都市がすべてやられると THE END です。ゲームが終わると、残った都市と弾がボーナスとして点数に足されます。
- 効果音と BGM が鳴ります（最初に画面を触る・クリックする・キーを押したときから）。タイトル画面の「♪ 音 ON／OFF」で消せます。選んだ方は覚えておきます。

## 気をつけること

- ランキングはその端末のブラウザの中にだけ保存されます（ほかの端末とは共有されません）。
- iPhone では、マナーモード（横のスイッチ）のときは音が鳴らないことがあります。
- iPhone の Safari は、しばらく開かなかったサイトの保存データを消すことがあり、ランキングが消えることがあります。ホーム画面に置いて（共有ボタン →「ホーム画面に追加」）遊ぶと消えにくくなります。

## 新しい版と困ったとき

- 新しい版が出ると、タイトルか TOP10 の画面の上に「新しい版があります」と「更新」ボタンが出ます。好きなときに「更新」を押すと新しい版になります（遊んでいる最中に勝手に変わることはありません）。ランキングは残ります。
- 起動して 8 秒たっても画面が出ないときは、「再読み込み」と「キャッシュを消して再読み込み」のボタンが出ます。どちらを押してもランキングは消えません。

## 開発

Node.js 24 以上が要ります。

```sh
npm ci
npm run dev        # 手元で動かす
npm run verify     # lint・単体テスト・build・dist の検査・文書の検査
npm run test:e2e   # E2E（先に npm run build）
```

開発の進め方と記録（プロダクトバックログ・スプリントの記録・設計）は `docs/` にあります。同じゲームを作り直すための仕様は `docs/reproduction-specification.md` にまとめています。

### ファイルの構成

| 場所 | 中身 |
| :--- | :--- |
| `src/core/` | ゲームの決まり（ウェーブ・敵・迎撃・爆風・点・TOP10・名前）。画面やブラウザに触れない |
| `src/render/` | 画面に描く（ゲーム画面・タイトル・TOP10・文字） |
| `src/storage/` | TOP10 の保存と読み込み（ブラウザの localStorage） |
| `src/app/` | 入力・画面の大きさ・名前の入力欄・更新の帯・クレジット画面・PWA |
| `src/main.ts` | 全部を組み立てる |
| `public/` | 起動の復旧（`boot.js`）とアイコン（本番・プレビュー） |
| `channels.mjs` | 本番とプレビューの違い（URL・名前・色） |
| `tests/unit/`・`e2e/` | 単体テストと E2E（ブラウザを動かすテスト） |
| `scripts/` | 検査（dist・文書・README）・版を上げる・公開の build |
| `.github/workflows/` | CI（PR ごとのテスト）と GitHub Pages への公開 |
| `docs/` | プロダクトバックログ・設計・テストの文書・スプリントの記録・進め方 |
